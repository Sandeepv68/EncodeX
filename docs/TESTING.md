## 📋 Commands

```bash
# Run all tests
npm test

# Watch mode
npm run test:watch

# With coverage report
npm run test:coverage

# Unit tests only
npm run test:unit

# Integration tests (matches src/**/*.integration.{test,spec}.{ts,tsx})
npm run test:integration

# E2E tests (requires build)
npm run test:e2e

# MCP-focused E2E tests (requires build)
npm run test:e2e:mcp

# Performance suites
npm run perf
```

Coverage reports are generated in `coverage/`:

- `coverage/index.html` — browsable HTML
- `coverage/lcov.info` — LCOV for IDE integration

## 🛠️ Test Setup

The test environment (`src/test-setup.ts`) provides:

- Mocked `useTranslation` from `react-i18next` with English key mapping and interpolation
- Mocked `electronAPI` on `globalThis` covering all IPC methods
- Registers `@testing-library/jest-dom/vitest` matchers

## 🌐 E2E Tests

End-to-end tests live in `e2e/` and run through Vitest (node environment, 60s timeouts), using Playwright's Electron automation to drive the packaged app. Write specs live under `e2e/specs/`, the MCP specs under `e2e/mcp/`, and the CLI spec at `e2e/cli.spec.ts`; 39 test/spec files run in total. They are gated behind the `E2E` env var or CI:

| File              | What's Covered                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------- |
| `e2e/cli.spec.ts` | CLI mode: `--help`/`-h`, subcommands (`convert`, `info`, `capabilities`, `compress`, `extract-audio`, `remux`, `demux`, `batch`), legacy flat syntax, global flags (`--quiet`, `--no-color`, `--theme`) |
| `e2e/mcp/*.spec.ts` | MCP stdio/HTTP transports, embedded GUI server, MCP Apps UI, and VS Code client/UI integration |
| `e2e/specs/settings-mcp.spec.ts`, `settings-ai.spec.ts` | Embedded MCP settings and AI-provider settings |
| `e2e/specs/remux-demux-filters.spec.ts`, `copilot*.spec.ts`, `profiles.spec.ts`, `terms-gate.spec.ts` | Remux/demux, video filters, Copilot planning/saved chats, profiles, and the Terms gate |
| `e2e/specs/shell.spec.ts` | App shell: window title, `electronAPI` presence, all nav routes, drawer navigation, window controls, language menu |
