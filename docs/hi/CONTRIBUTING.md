# EncodeX को बेहतर बनाने में मदद करें

EncodeX मुफ़्त है और स्वयंसेवकों से बनता है — और मदद के लिए प्रोग्रामर होना ज़रूरी नहीं। कोई भी इन तरीक़ों से योगदान दे सकता है:

- **जब कुछ टूटे, बताएँ।** ऐप बंद हो जाए या फ़ाइल न बदले, तो [एक issue खोलें](https://github.com/Sandeepv68/EncodeX/issues) और बताएँ क्या हुआ। आम यूज़र्स की रिपोर्ट सोने जैसी होती हैं।
- **आइडिया सुझाएँ।** चाहते हैं EncodeX कोई ऐसा काम करे जो अभी नहीं करता? बताइए — कई फ़ीचर्स यूज़र्स के सुझावों से ही बने हैं।
- **अनुवाद करें।** EncodeX 35+ भाषाएँ बोलता है, और अनुवादकों का स्वागत हमेशा है। आपकी भाषा ग़ायब है या अटपटी लगती है? मदद से ठीक हो सकता है।
- **बात फैलाएँ।** दोस्तों को EncodeX बताएँ, रिव्यू लिखें या ट्यूटोरियल बनाएँ।

## संपर्क करें

सवाल हैं, आइडिया हैं, या बस हेलो कहना है? डेवेलपर को सीधे **[developer@encodex.in](mailto:developer@encodex.in)** पर ईमेल करें — यूज़र्स का फ़ीडबैक हमेशा स्वागत योग्य है।

## डेवेलपर्स के लिए

कोड देना चाहते हैं? ऐसे शुरू करें:

### डेवलपमेंट

```bash
npm run dev          # हॉट-रीलोड डेव मोड
npm run electron:dev # Electron विंडो समेत पूरा डेव एनवायरनमेंट
npm run build        # पूरा बिल्ड
npm start            # बनी हुई ऐप चलाएँ
```

### प्रोजेक्ट कन्वेंशन

- **TypeScript** — strict मोड, जहाँ तक हो सके `any` नहीं।
- **React** — hooks वाले फंक्शनल कंपोनेंट।
- **State** — ग्लोबल स्टेट के लिए Zustand stores।
- **IPC** — सभी चैनल `src/shared/ipc-channels.ts` में।
- **Constants** — हार्डकोडेड वैल्यू `src/shared/` की constants फ़ाइलों में।
- **i18n** — सभी यूज़र-फेसिंग टेक्स्ट `src/renderer/i18n/locales/` में।

### Pull Request प्रक्रिया

1. सुनिश्चित करें कि बिल्ड पास हो: `npm run build`
2. UI टेक्स्ट जोड़ें या बदलें तो लोकेल फ़ाइलें अपडेट करें।
3. हर PR को एक ही मुद्दे पर केंद्रित रखें।
