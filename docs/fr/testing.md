# Tests

## Commandes

```bash
# Run all tests
npm test

# Watch mode
npm run test:watch

# With coverage report
npm run test:coverage

# Unit tests only
npm run test:unit

# Integration tests (matches src/**/*.integration.{test,spec}.{ts,tsx})
npm run test:integration

# E2E tests (requires build)
npm run test:e2e
```

Les rapports de couverture sont générés dans `coverage/` :

- `coverage/index.html` — HTML navigable
- `coverage/lcov.info` — LCOV pour l'intégration IDE

## Configuration des tests

L'environnement de test (`src/test-setup.ts`) fournit :

- Mock de `useTranslation` de `react-i18next` avec mapping des clés vers l'anglais et interpolation
- Mock de `electronAPI` sur `globalThis` couvrant toutes les méthodes IPC
- Enregistrement des matchers `@testing-library/jest-dom/vitest`

## Tests E2E

Les tests end-to-end basés sur Playwright vivent dans `e2e/` (environnement node, timeouts de 60 s) et sont conditionnés à la variable d'environnement `E2E` ou à CI :

| Fichier              | Ce que ça couvre                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------- |
| `e2e/cli.spec.ts` | Mode CLI : `--help`/`-h`, sous-commandes (`convert`, `info`, `capabilities`, `compress`, `extract-audio`, `batch`), syntaxe à plat héritée, flags globaux (`--quiet`, `--no-color`, `--theme`) |
| `e2e/specs/shell.spec.ts` | Shell de l'app : titre de la fenêtre, présence de `electronAPI`, toutes les routes de navigation, navigation du drawer, contrôles de fenêtre, menu des langues |
| `e2e/specs/convert.spec.ts` | Page Convert : sélection de fichiers, autocomplétion de sortie, options codec/bitrate/échelle/pixel/transcoder, copie sans perte, conversion avec progression, pause/reprise, annuler |
| `e2e/specs/batch.spec.ts` | File par lots : état vide, ajout de fichiers via dialogue de revue, événements de file, progression en direct, tout annuler, filtre de statut, suppression de tâche, réordonnancement par glisser, confirmation de fermeture de fenêtre |
| `e2e/specs/audio-extract.spec.ts` | Extraction audio : bouton désactivé, sélection vidéo avec flux audio, changements de codec/bitrate, extraction avec toast de succès |
| `e2e/specs/image-compress.spec.ts` | Compression d'images : dropzone, sélection d'image avec aperçu, changements de format/qualité/échelle, compression avec toast de succès |
| `e2e/specs/media-info.spec.ts` | Media info : analyse vidéo (flux, détails des codecs), analyse image (données EXIF) |
| `e2e/specs/settings.spec.ts` | Réglages : cartes de thème, changement de thème, toujours visible, lancement à la connexion, persistance du mode hwaccel |
| `e2e/specs/logs.spec.ts` | Logs : émission d'entrées, filtrage par niveau, tout effacer, téléchargement avec toast |
| `e2e/specs/video-cut.spec.ts` | Découpe vidéo : bouton désactivé, timeline + forme d'onde + miniatures, bascule durée/heure de fin, glissement de la tête de lecture, découpe avec progression, annuler, nettoyage du formulaire |
| `e2e/specs/real-convert.spec.ts` | Tier B (réel) : conversion FFmpeg réelle sans mock (conditionnée à `E2E_REAL=1`) |
