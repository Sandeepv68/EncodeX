# Testes

## Comandos

```bash
# Run all tests
npm test

# Watch mode
npm run test:watch

# With coverage report
npm run test:coverage

# Unit tests only
npm run test:unit

# Integration tests (matches src/**/*.integration.{test,spec}.{ts,tsx})
npm run test:integration

# E2E tests (requires build)
npm run test:e2e
```

Os relatórios de cobertura são gerados em `coverage/`:

- `coverage/index.html` — HTML navegável
- `coverage/lcov.info` — LCOV para integração com IDEs

## Configuração de testes

O ambiente de testes (`src/test-setup.ts`) fornece:

- Mock do `useTranslation` do `react-i18next` com mapeamento de chaves para o inglês e interpolação
- Mock do `electronAPI` em `globalThis` cobrindo todos os métodos IPC
- Registro dos matchers `@testing-library/jest-dom/vitest`

## Testes E2E

Os testes end-to-end baseados em Playwright vivem em `e2e/` (ambiente node, timeouts de 60 s) e são condicionados à variável de ambiente `E2E` ou a CI:

| Arquivo              | O que cobre                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------- |
| `e2e/cli.spec.ts` | Modo CLI: `--help`/`-h`, subcomandos (`convert`, `info`, `capabilities`, `compress`, `extract-audio`, `batch`), sintaxe plana legada, flags globais (`--quiet`, `--no-color`, `--theme`) |
| `e2e/specs/shell.spec.ts` | Shell do app: título da janela, presença do `electronAPI`, todas as rotas de navegação, navegação do drawer, controles de janela, menu de idiomas |
| `e2e/specs/convert.spec.ts` | Página Convert: seleção de arquivos, autocompletar saída, opções de codec/bitrate/escala/pixel/transcoder, cópia sem perdas, conversão com progresso, pause/resume, cancelar |
| `e2e/specs/batch.spec.ts` | Fila de lotes: estado vazio, adicionar arquivos via diálogo de revisão, eventos da fila, progresso ao vivo, cancelar tudo, filtro de status, remover job, reordenar arrastando, confirmação de fechamento da janela |
| `e2e/specs/audio-extract.spec.ts` | Extração de áudio: botão desabilitado, seleção de vídeo com streams de áudio, mudanças de codec/bitrate, extração com toast de sucesso |
| `e2e/specs/image-compress.spec.ts` | Compressão de imagens: dropzone, seleção de imagem com preview, mudanças de formato/qualidade/escala, compressão com toast de sucesso |
| `e2e/specs/media-info.spec.ts` | Media info: análise de vídeo (streams, detalhes de codecs), análise de imagem (dados EXIF) |
| `e2e/specs/settings.spec.ts` | Configurações: cartões de tema, troca de tema, sempre visível, iniciar com o sistema, persistência do modo hwaccel |
| `e2e/specs/logs.spec.ts` | Logs: emissão de entradas, filtragem por nível, limpar tudo, download com toast |
| `e2e/specs/video-cut.spec.ts` | Corte de vídeo: botão desabilitado, timeline + forma de onda + miniaturas, alternância duração/hora final, arrasto da cabeça de reprodução, corte com progresso, cancelar, limpeza do formulário |
| `e2e/specs/real-convert.spec.ts` | Tier B (real): conversão FFmpeg real sem mocks (condicionado a `E2E_REAL=1`) |
