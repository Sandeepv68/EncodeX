# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in EncodeX, please report it by
opening a [security advisory](https://github.com/your-org/encodex/security/advisories/new).

Please do **not** report security vulnerabilities through public GitHub issues.

## Response

We will acknowledge receipt within 48 hours and provide an estimated timeline
for a fix. Security fixes will be prioritized and released as soon as possible.
