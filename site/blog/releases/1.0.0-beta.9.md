# EncodeX V1.0.0-beta.9

**Released:** 2026-11-24
**Tag:** [`v1.0.0-beta.9`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.9)

## What's New

This release completes the PostHog rollout on top of `1.0.0-beta.8`.

- **Privacy-aware analytics** — product events, pageviews, exception capture and logs now flow through the existing consent/telemetry controls.
- **Production-only portal** — dashboards, saved insights, cohorts, session replays, survey targeting and log alerts are filtered to `environment = production`, with test accounts excluded.
- **Consistent build config** — the renderer now derives the same PostHog `environment` and `channel` values as the main process, so packaged builds report production data correctly.
- **Documentation cleanup** — analytics reports and dialog-planning documents now live under `analytics/posthog/` and `plans/`.

For the beta.8 updater fix and beta.7 dialog polish, see the [1.0.0-beta.8 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8) and the [1.0.0-beta.7 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7).

## Upgrade

Update from the app's **Check for Updates** action, or download the installers from the [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.9). As always, conversion stays local to your machine — no account, upload, or watermark.
