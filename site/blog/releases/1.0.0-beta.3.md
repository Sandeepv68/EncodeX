# EncodeX V1.0.0-beta.3

**Released:** 2026-09-15
**Tag:** [`v1.0.0-beta.3`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.3)

## What's New

This release brings the biggest feature set since the initial beta: a full conversion profile system, a first-run onboarding experience, batch folder import, a privacy-safe analytics backbone, and major website expansion across 7 languages.

---

## Conversion Profiles — 140+ Presets

EncodeX now ships with over 140 built-in conversion profiles organized into 8 categories. Instead of manually picking codecs, bitrates, and containers every time, choose a preset and everything fills in automatically.

- **Web & Social** — YouTube (4K through 360p), Instagram Reels/Stories/Posts, TikTok, Facebook, X
- **Devices** — iPhone, iPad, Apple TV, Android, PlayStation 4/5, Xbox One/Series X|S, Nintendo Switch
- **Video** — MP4, MKV, MOV, WebM, AVI, MPEG-1/2 variants with H.264, H.265, AV1, VP9, and more
- **Professional** — Apple ProRes (422 LT through 4444 XQ), Avid DNxHR, CineForm, FFV1, HuffYUV
- **Streaming** — HLS and DASH with configurable segment durations
- **Audio** — MP3, AAC, Opus, FLAC, ALAC, WAV, AIFF, Dolby AC-3/Dolby Digital Plus
- **Images** — JPEG, PNG, WebP, AVIF, TIFF, BMP, GIF
- **Advanced** — Raw FFmpeg passthrough, null output for benchmarking, custom profiles

Profiles work on both the **Convert** page and the **Batch Queue**. Select a profile and all encoding fields update instantly.

Custom profiles can be created, edited, and deleted through the built-in profile editor. Custom profiles are saved locally and persist across sessions.

[Read the full profile guide](/blog/releases/conversion-profiles)

## First-Run Onboarding

New users are greeted with a **Getting Started** card on first launch. Pick a goal — convert, compress, extract audio, or trim — and EncodeX takes you straight to the right tool.

The card is non-gating: it can be dismissed with one click and never appears again once a goal is chosen or skipped. It tracks completion via a local flag and respects reduced-motion preferences.

---

## Batch Queue: Folder Import

The batch queue now supports **Add Folder** alongside Add Files. Drop an entire directory of media files into the queue in one action, and EncodeX filters to only supported formats automatically.

When no supported files are found, the queue displays a clear "No supported media files found" message instead of an empty state.

---

## Privacy-Safe Product Analytics

EncodeX introduces a lightweight analytics system that helps us understand how the app is used **without ever touching your files**.

The design is simple:

- **No new network endpoints.** Events ride the existing Sentry monitoring breadcrumb channel.
- **Zero PII by construction.** Payloads contain only categorical data: platform, architecture, encoder type, event names. No file paths, filenames, or identifiers.
- **Consent-gated.** When telemetry is disabled in Settings, every analytics call is a no-op.
- **Never throws.** Analytics failures are swallowed and logged at debug level — the app is never affected.

Events tracked include app launch, conversion start/complete/fail, batch completion, profile application, hardware acceleration detection, and CLI invocation.

## Vertical & Square Resolutions

The resolution picker now includes **vertical** (2160x3840, 1080x1920, 720x1280) and **square** (1080x1080) options — useful for social media content, Stories, Reels, and TikTok.

---

## 55 Locales with Full Coverage

EncodeX now ships with translation files for **55 locales** (from Afrikaans to Vietnamese), each updated to include all new UI strings from the profile system and onboarding card. The `batchQueue` section has also been expanded with folder-import and empty-state strings.

---

## Website & Documentation

The EncodeX website received a major expansion:

- **100+ new pages** across 7 language versions (en, es, fr, de, pt, zh, hi)
- **Codec guides** for H.264, H.265, AV1, VP9, and ProRes
- **Format conversion guides** for 20+ common workflows (MKV to MP4, MOV to MKV, etc.)
- **Compression guides** for MP4 and MKV
- **Platform-specific landing pages** for Windows, Mac, and Linux
- **Blog posts** on video compression, GPU acceleration, batch conversion, archival formats, and more
- **RSS feed** generation and updated sitemaps

## Dev Tooling

- **Screenshot capture** — `Ctrl+Alt+S` (Cmd+Alt+S on macOS) in dev mode saves a PNG snapshot of the main window for documentation and testing
- **Custom ESLint rules** — `no-hardcoded-strings`, `no-hardcoded-rem`, `no-inline-styles`, and `text-allowlist` enforce i18n and styling hygiene
