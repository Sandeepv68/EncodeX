# EncodeX V1.0.0-beta.6

**Released:** 2026-11-19
**Tag:** [`v1.0.0-beta.6`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6)

## What's New

This is the biggest beta since the MCP server first landed. The Copilot has a new conversation experience, MCP Apps are now React views that render inside EncodeX and in third-party hosts, remux/demux and video filters are first-class across the app/CLI/MCP, and the whole project has been through another production-readiness, security, and documentation pass.

---

## Copilot & Local AI

- **New conversation UI** — ChatGPT-style layout with a Lexical composer, suggestion placeholder, advanced options popover, and a provider logo-grid connect flow.
- **Saved chats** — a side panel keeps your conversations, now as an overlay so the transcript never reflows when it opens.
- **Local provider support** — Ollama is supported alongside OpenAI, Anthropic, Gemini, and the offline `rules` provider, with provider status, model discovery, key removal, and transient `429/5xx` retry with backoff.
- **AI extras** — transcribe, summarize, chapters, transcript search, translate, find-similar, BMF availability detection, and AI rules connect are wired through the operation router.
- **Auto-growing composer** — the Copilot input expands as you type and keeps long prompts comfortable to edit.

---

## MCP 2.x and MCP Apps

- **MCP SDK 2.x** — the server now runs on the split 2.x packages and exposes the browser-side MCP Apps `App` API used by the view pipeline.
- **React MCP App views** — the interactive views were rewritten against EncodeX's own design system and bundled into self-contained documents, so they look the same in Claude Desktop, VS Code, Cursor, ChatGPT, Goose, or MCPJam.
- **Views inside the Copilot** — plans render inline: analysis shows the inspector card, and queue-backed operations show a live dashboard backed by the same job manager the app uses.
- **More views and tools** — `ui://encodex/profiles` and `ui://encodex/capabilities` join the inspector, plan, compression-lab, error, and batch dashboard views. New AI tools include `analyze_media`, `recommend_settings`, `estimate_conversion`, `validate_output`, `compress_to_target`, `analyze_folder`, `explain_error`, `advise_encoding`, and `quality_report`.
- **Standalone HTTP transport** — `npm run mcp:http` provides a loopback-only server with optional bearer auth, session and body-size caps, and Host/Origin checks. `npm run mcp:host-check` verifies every served view document.
- **Breaking protocol note** — MCP 2.x removes the `tasks/*` side-channel. `convert_media` and `batch_convert` return the same immediate `jobId` receipt; continue with `get_job` / `list_jobs` polling as before.

---

## Media Workflows

- **Remux and Demux** — dedicated pages for lossless container changes and stream extraction, available from the app, CLI, and MCP surfaces.
- **Video filters** — crop, frame rate, deinterlace, denoise, sharpen, color, grayscale, blur, and custom filter chains work across Convert, Batch, Remux, Demux, CLI, and MCP, with clear warnings when a filter forces re-encoding.
- **Desktop notifications** — opt-in OS/taskbar alerts for batch and mux queue completion, failures, and background queue summaries, with click-to-focus and queue navigation.
- **Queue polish** — a dedicated mux queue, per-tab condense, tabular job details, and improved status handling.
- **Logs in their own window** — the Logs page can be detached, plus free-text search across stored entries.
- **Smarter trimming** — trimmed cuts no longer inherit the source chapter timeline, so output durations report correctly.

---

## Security & Quality

- All GitHub Actions are pinned to commit SHAs, the release workflow is least-privilege, release secrets are generated at build time, and the updater download sink enforces HTTPS.
- CodeQL alerts were cleared, a blocking dependency-audit gate was added with a documented allowlist, and a committed IPC-abuse sweep drives hostile input at every `ipcMain.handle` channel.
- New CI tiers cover sharded/diff-scoped mutation testing, media fuzzing, locale matrix, RTL, accessibility, render budgets, and performance budgets.
- CLI error output no longer leaks Node.js stack frames, runtime FFmpeg failures are classified correctly, and super-linear regular expressions were removed from bearer-token and `matchMedia` handling.

---

## Documentation & Website

- README, wiki, docs, plans, and localized site content were synced with the current codebase and drift-checked.
- Website canonical URLs, internal links, sitemap entries, hreflang alternates, and JSON-LD now consistently use trailing-slash URLs, reducing duplicate and redirect-style indexing noise.
- Release notes and feature pages now cover the new Copilot, MCP, remux/demux, filter, and notification workflows.

## Upgrade

Update from the app's **Check for Updates** action, or download the installers from the [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6). As always, conversion stays local to your machine — no account, upload, or watermark.
