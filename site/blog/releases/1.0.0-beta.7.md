# EncodeX V1.0.0-beta.7

**Released:** 2026-11-20
**Tag:** [`v1.0.0-beta.7`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7)

## What's New

This is a small polish release on top of `1.0.0-beta.6`.

- **Dialog close button** — the X is now pinned to the trailing edge of the modal header, so it stays in place even when the title is long.
- **Lighter dividers** — the header and footer rules use a subtler, theme-aware color in both light and dark themes.

For the larger Copilot, MCP 2.x, remux/demux, video filter, mux queue and security changes, see the [1.0.0-beta.6 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6).

## Upgrade

Update from the app's **Check for Updates** action, or download the installers from the [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7). As always, conversion stays local to your machine — no account, upload, or watermark.
