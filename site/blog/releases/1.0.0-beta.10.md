# EncodeX V1.0.0-beta.10

**Released:** 2026-11-25
**Tag:** [`v1.0.0-beta.10`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.10)

## What's New

This is a small updater fix on top of `1.0.0-beta.9`.

- **Updater directory fix** — the updater now creates `%TEMP%\EncodeX-updater` before writing the installer, so a missing cache directory no longer fails the update with `ENOENT`.
- **Clean failure handling** — if the directory cannot be created, the download reports an error instead of leaving the UI waiting on a failed write stream.
- **Build and CI hardening** — the optional PostHog sourcemap plugin is tolerated when missing, Windows uses the packaged app icon, and the media-info IPC event-budget test is stabilized.

For the beta.9 PostHog rollout and beta.8 updater fix, see the [1.0.0-beta.9 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.9) and the [1.0.0-beta.8 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8).

## Upgrade

Update from the app's **Check for Updates** action, or download the installers from the [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.10). As always, conversion stays local to your machine — no account, upload, or watermark.
