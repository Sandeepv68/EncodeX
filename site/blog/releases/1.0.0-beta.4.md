# EncodeX V1.0.0-beta.4

**Released:** 2026-09-20
**Tag:** [`v1.0.0-beta.4`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.4)

## What's New

This release is a two-parter: a pair of brand-new features and a serious round of security hardening. Fix a sideways phone clip without losing quality, let an AI assistant drive your conversions through MCP, and rest easy knowing the command line and file handling were audited and locked down.

---

## Rotation & Mirror

The most-requested fix-it tool is here. **Rotation & Mirror** lets you rotate videos and photos **90°, 180°, or 270° clockwise** and flip them **horizontally or vertically** — on the Convert page and in the Batch Queue.

Fixing a sideways clip takes seconds, and when your output is MP4, MOV, or MKV in stream-copy (lossless) mode, the rotation is saved as standard display metadata — **nothing is re-encoded** and quality is untouched. For other formats or when you mirror the image, EncodeX applies an efficient FFmpeg filter chain instead.

## Built-In MCP Server: Let AI Drive Your Media Conversions

EncodeX can now act as a **Model Context Protocol (MCP) server**, so AI assistants — Claude Desktop, Claude Code, Cursor, VS Code, and any MCP-compatible client — can convert videos, extract audio, compress images, trim clips, and manage batch jobs through EncodeX with nothing but a plain-language request.

- **19 tools** across conversion, inspection, job management, and GUI parity
- **3 resources** (`encodex://profiles`, `encodex://capabilities`, `encodex://codecs`) for capability discovery
- **4 prompt templates** for the most common tasks
- **Two transports**: a standalone `encodex --mcp` stdio server, and an embedded loopback HTTP server for GUI mode
- **Private by design**: loopback-only, optional bearer token, clean shutdown, and zero uploads — everything runs locally

Conversions are asynchronous, so a long render never freezes the conversation — your assistant starts the job, gets an ID, and polls or cancels later.

[Read the full MCP guide](/blog/releases/mcp-server-support)

## Security Hardening

A batch of CodeQL alerts and audit findings were fixed and locked down with regression tests:

- **Regular expression injection** in the CLI output parsing — user input can no longer alter the pattern being compiled
- **Prototype-polluting function** in the translation update script — object keys are now built safely
- **Insecure temporary file** handling in the job queue tests
- **File system race condition** in image metadata lookup — files are now verified atomically before use
- **Log injection** (CWE-117) — line-breaking characters are sanitized from log arguments so user input can't forge log lines
- **Command injection hardening** in the BMF media probe — the binary is now invoked via `execFileSync` with explicit arguments instead of a shell string

Every fix ships with a regression test to keep the vulnerabilities from coming back.
