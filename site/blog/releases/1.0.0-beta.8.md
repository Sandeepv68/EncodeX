# EncodeX V1.0.0-beta.8

**Released:** 2026-11-20
**Tag:** [`v1.0.0-beta.8`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8)

## What's New

This is a small fix release on top of `1.0.0-beta.7`.

- **Update-available event** — the updater now forwards a detected update to the renderer. The production IPC guard validated `asset.fileName`, but main sends `asset.name/url/size`, so the event was silently dropped.
- **No more stuck UI** — **Check for Updates** now shows the available update instead of staying on "Checking for updates".

For the beta.7 dialog polish and the larger Copilot, MCP 2.x, remux/demux, video filter and mux queue changes, see the [1.0.0-beta.7 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7) and the [1.0.0-beta.6 release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6).

## Upgrade

Update from the app's **Check for Updates** action, or download the installers from the [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8). As always, conversion stays local to your machine — no account, upload, or watermark.
