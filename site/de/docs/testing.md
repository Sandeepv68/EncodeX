# Tests

## Befehle

```bash
# Run all tests
npm test

# Watch mode
npm run test:watch

# With coverage report
npm run test:coverage

# Unit tests only
npm run test:unit

# Integration tests (matches src/**/*.integration.{test,spec}.{ts,tsx})
npm run test:integration

# E2E tests (requires build)
npm run test:e2e
```

Die Coverage-Berichte werden in `coverage/` erzeugt:

- `coverage/index.html` — navigierbares HTML
- `coverage/lcov.info` — LCOV für IDE-Integration

## Test-Setup

Die Testumgebung (`src/test-setup.ts`) stellt bereit:

- Mock von `useTranslation` aus `react-i18next` mit Key-Mapping auf Englisch und Interpolation
- Mock von `electronAPI` auf `globalThis`, der alle IPC-Methoden abdeckt
- Registrieren der Matcher `@testing-library/jest-dom/vitest`
