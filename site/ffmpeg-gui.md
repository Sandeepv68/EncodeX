# A Powerful GUI for FFmpeg

**FFmpeg** is the engine behind most video conversion tools — but it's a command-line program that's intimidating to use. **EncodeX** gives you a friendly, visual **FFmpeg frontend** that wraps all of that power in an interface anyone can use, with zero commands to type.

## Why Put a GUI Around FFmpeg?

FFmpeg is incredibly capable. The problem is that using it means memorizing commands like:

```bash
ffmpeg -i input.mkv -c:v libx264 -crf 18 -c:a aac output.mp4
```

If that looks like a foreign language to you, you're not alone. A **FFmpeg GUI** turns that into a simple set of menus and buttons:

- **Pick your file** by dragging it onto the window
- **Pick your output** — a device, a platform, or a format like MP4
- **Click Convert** and let EncodeX do the rest

## What You Can Do With the EncodeX FFmpeg GUI

- **Convert video and audio** between dozens of formats — MP4, MKV, AVI, MOV, WebM, MP3, FLAC, WAV and more
- **Compress videos** to shrink file size without wrecking quality
- **Trim clips** visually — drag two handles on a timeline, done
- **Extract audio** from a video and save it as an MP3
- **Batch process** whole folders of files in one go
- **Hardware acceleration** via NVENC, QSV, AMF, VAAPI and VideoToolbox for much faster encoding
