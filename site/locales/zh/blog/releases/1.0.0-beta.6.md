# EncodeX V1.0.0-beta.6

**发布日期：** 2026-11-19
**标签：** [`v1.0.0-beta.6`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6)

## 新增内容

这是自 MCP 服务器首次登陆以来规模最大的一个 beta 版本。Copilot 拥有了全新的对话体验，MCP Apps 现在是可在 EncodeX 内部以及第三方宿主中渲染的 React 视图，remux/demux 和视频滤镜在 app/CLI/MCP 各界面中都成为一等功能，整个项目也完成了又一轮生产就绪、安全和文档方面的打磨。

---

## Copilot 与本地 AI

- **全新的对话界面** — 类 ChatGPT 布局，配备 Lexical 编辑器、建议占位符、高级选项弹出层，以及提供商徽标网格连接流程。
- **已保存的聊天** — 侧边面板用于保存你的对话，现在以覆盖层形式呈现，打开时不会导致对话记录重排。
- **本地提供商支持** — 除 OpenAI、Anthropic、Gemini 和离线 `rules` 提供商外，现已支持 Ollama，并提供提供商状态、模型发现、密钥移除，以及针对瞬时 `429/5xx` 错误的退避重试。
- **AI 扩展功能** — 转录、摘要、章节、转录搜索、翻译、查找相似内容、BMF 可用性检测以及 AI 规则连接均已通过操作路由器接入。
- **自动增高的编辑器** — Copilot 输入框会随着你的输入自动扩展，让长提示词的编辑更加舒适。

---

## MCP 2.x 与 MCP Apps

- **MCP SDK 2.x** — 服务器现在运行在拆分后的 2.x 包上，并暴露视图管线所使用的浏览器端 MCP Apps `App` API。
- **React MCP App 视图** — 交互式视图已基于 EncodeX 自有设计系统重写，并打包为自包含文档，因此在 Claude Desktop、VS Code、Cursor、ChatGPT、Goose 或 MCPJam 中都能保持一致外观。
- **Copilot 内的视图** — 计划会内联渲染：分析显示检查器卡片，而基于队列的操作则显示由应用所使用的同一任务管理器驱动的实时仪表盘。
- **更多视图和工具** — `ui://encodex/profiles` 和 `ui://encodex/capabilities` 加入了检查器、计划、compression-lab、错误和 batch dashboard 视图。新的 AI 工具包括 `analyze_media`、`recommend_settings`、`estimate_conversion`、`validate_output`、`compress_to_target`、`analyze_folder`、`explain_error`、`advise_encoding` 和 `quality_report`。
- **独立 HTTP 传输** — `npm run mcp:http` 提供仅回环的服务器，支持可选 bearer 认证、会话与请求体大小限制，以及 Host/Origin 检查。`npm run mcp:host-check` 会验证每个提供的视图文档。
- **破坏性协议说明** — MCP 2.x 移除了 `tasks/*` 旁路通道。`convert_media` 和 `batch_convert` 返回相同的即时 `jobId` 回执；请像以前一样继续通过 `get_job` / `list_jobs` 轮询。

## 媒体工作流

- **Remux 与 Demux** — 用于无损容器更改和流提取的专用页面，可在 app、CLI 和 MCP 各界面中使用。
- **视频滤镜** — 裁剪、帧率、去隔行、降噪、锐化、颜色、灰度、模糊以及自定义滤镜链可在 Convert、Batch、Remux、Demux、CLI 和 MCP 中使用，并在滤镜强制重新编码时给出明确警告。
- **桌面通知** — 可选的操作系统/任务栏通知，用于批量和 mux 队列完成、失败以及后台队列摘要，支持点击聚焦和队列导航。
- **队列优化** — 新增专用 mux 队列、按标签页折叠、表格式任务详情，以及改进的状态处理。
- **独立窗口日志** — 日志页面可分离显示，并支持对已存储条目进行自由文本搜索。
- **更智能的裁剪** — 裁剪后的片段不再继承源文件的章节时间线，因此输出时长可以正确显示。

## 安全与质量

- 所有 GitHub Actions 都已固定到提交 SHA，发布工作流采用最小权限原则，发布密钥在构建时生成，更新器下载目标强制使用 HTTPS。
- CodeQL 警报已清除，新增了带文档化允许列表的阻塞式依赖审计门禁，并通过已提交的 IPC 滥用扫描向每个 `ipcMain.handle` 通道施加恶意输入。
- 新的 CI 层级覆盖分片/差异范围变异测试、媒体模糊测试、语言环境矩阵、RTL、可访问性、渲染预算和性能预算。
- CLI 错误输出不再泄露 Node.js 堆栈帧，运行时 FFmpeg 失败会被正确分类，并且从 bearer-token 和 `matchMedia` 处理中移除了超线性正则表达式。

## 文档与网站

- README、wiki、docs、plans 和本地化站点内容已与当前代码库同步并完成偏差检查。
- 网站的规范 URL、内部链接、站点地图条目、hreflang alternates 和 JSON-LD 现在统一使用带尾部斜杠的 URL，减少重复和重定向式索引噪音。
- 发布说明和功能页面现已涵盖新的 Copilot、MCP、remux/demux、滤镜和通知工作流。
