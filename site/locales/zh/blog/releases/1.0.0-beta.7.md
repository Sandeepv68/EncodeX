# EncodeX V1.0.0-beta.7

**发布日期：** 2026-11-20
**标签：** [`v1.0.0-beta.7`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7)

## 新功能

这是在 `1.0.0-beta.6` 基础上的一个小幅优化版本。

- **关闭按钮** — X 现在固定在对话框标题栏末尾，即使标题很长也不会移动。
- **更浅的分隔线** — 标题栏和底部栏的分隔线使用更柔和、随主题变化的颜色，浅色和深色主题都适用。

Copilot、MCP 2.x、remux/demux、视频滤镜、mux 队列和安全方面的较大变更见 [1.0.0-beta.6 版本](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6)。

## 升级

可通过应用内的 **Check for Updates** 操作进行更新，或从 [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7) 下载安装程序。与往常一样，转换始终在你的本地机器上完成——无需账户、无需上传、无水印。
