# 旋转与镜像视频

用手机拿反了拍视频？这事儿我们谁都经历过。从今天起，EncodeX 可以帮你解决：**旋转与镜像**功能可以将视频和照片**顺时针旋转 90°、180° 或 270°**，并支持**水平或垂直**翻转——直接从转换页面和批量队列就能完成。

## 一键搞定

修正一个侧拍的片段只需几秒：

1. 打开**转换**页面（或把文件加入**批量队列**）
2. 选择任意视频或图片作为源文件
3. 在设置区域，从**旋转**下拉菜单选择一个角度——顺时针 `90°`、`180°` 或 `270°`——并用**水平翻转** / **垂直翻转**开关进行镜像
4. 转换

就这样。输出文件的方向与你的预期完全一致。视频**和**图片都能用，既可以单次转换，也能用于批量任务（转码和图片压缩操作均支持）。

## 两种工作方式

根据你的输出格式，旋转通过两种机制之一实现：

### 无损元数据旋转（无需重新编码）

当输出格式为 **MP4、MOV 或 MKV**，并且使用**流复制（无损复制）**模式且只设置旋转角度（不带镜像）时，EncodeX 会将旋转保存为标准显示元数据（`rotate=`）。播放器在播放时自动旋转视频——**画质完全不受影响**，任务在几秒内完成，因为什么都不用重新编码。镜像不走这条路：翻转图像一定会改变像素，所以镜像始终需要重新编码。

如果你的容器支持，转换页面会显示一条提示，说明旋转以无损方式应用。如果输出容器*不支持*（例如 WebM、FLV、GIF 以及图片输出），你会看到一条警告，附带**关闭无损复制**按钮，一键切换到重新编码路径。

### 像素旋转（重新编码）

对于其他任何格式——或只要镜像了视频——EncodeX 都会用 FFmpeg 滤镜链（`transpose` + `hflip`/`vflip`）重新编码画面帧，并与现有的 `scale` 滤镜无缝合并。由于旋转按 90° 步进进行，没有插值运算，画面始终保持清晰。

## 批量队列同样内置

旋转和镜像不只限于单次转换。它们同样是**批量队列**的一部分——在批量面板上设置即可应用到整个批次，也可以在单个任务的选项对话框中修改。批量任务始终重新编码，因此旋转和镜像会与编码器、码率和缩放一样，成为任务选项的一部分。

## 背后的原理

- 旋转映射为 FFmpeg 的 `transpose` 滤镜：90° 用 `transpose=1`，180° 用 `transpose=2,transpose=2`，270° 用 `transpose=2`（添加翻转时附带镜像）。
- 当同时设置了 `scale` 时，所有内容会合并到一个 `-vf` 参数中（先缩放、后旋转），保持滤镜链高效运行。
- 在流复制模式下，搭配受支持的容器，会在 `-c copy` 旁边写入 `-metadata:s:v rotate=<度>` 标记——不解码、不重编码、画质无损。
- 批量队列和图片压缩面板提供相同的控制项，`compress_image` 任务也以相同方式旋转图片。
