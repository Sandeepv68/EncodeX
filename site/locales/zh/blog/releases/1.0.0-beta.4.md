# EncodeX V1.0.0-beta.4

**发布日期：** 2026-09-20
**标签：** [`v1.0.0-beta.4`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.4)

## 新增内容

这个版本分为两部分：多个全新功能，以及一次认真的安全加固。无需损失画质即可修复拍歪的片段，通过 MCP 让 AI 助手驱动你的格式转换，并且可以放心——命令行和文件处理都经过了审计并被锁定。

---

## 旋转与镜像

呼声最高的修复工具来了。**旋转与镜像** 可让你将视频和照片**按顺时针方向旋转 90°、180° 或 270°**，并**水平或垂直**翻转——在转换页面和批量队列中都可以使用。

修复拍歪的片段只需几秒；当你的输出是 MP4、MOV 或 MKV 且使用流复制（无损）模式时，旋转会保存为标准显示元数据——**完全不重新编码**，画质不受影响。对于其他格式，或者当你镜像画面时，EncodeX 会改用高效的 FFmpeg 滤镜链处理。

[阅读完整的旋转指南](/blog/releases/rotate-and-mirror-videos)

## 内置 MCP 服务器：让 AI 驱动你的媒体转换

EncodeX 现在可以作为**模型上下文协议（MCP）服务器**运行，因此 AI 助手——Claude Desktop、Claude Code、Cursor、VS Code 以及任何兼容 MCP 的客户端——只需一句自然语言请求，就能通过 EncodeX 转换视频、提取音频、压缩图片、裁剪片段并管理批量任务。

- **转换、检查、任务管理和 GUI 对齐共 19 个工具**
- **3 个资源**（`encodex://profiles`、`encodex://capabilities`、`encodex://codecs`）用于能力发现
- **4 个提示词模板**覆盖最常见任务
- **两种传输方式**：独立的 `encodex --mcp` stdio 服务器，以及用于 GUI 模式的内置回环 HTTP 服务器
- **默认隐私安全**：仅回环地址、可选 Bearer 令牌、干净关闭、零上传——一切都在本地运行

转换是异步的，所以长时间渲染不会冻结对话——你的助手启动任务、获得 ID，之后可以轮询或取消。

[阅读完整的 MCP 指南](/blog/releases/mcp-server-support)

## 安全加固

一批 CodeQL 警报和审计发现已被修复，并附带回归测试加以锁定：

- **CLI 输出解析中的正则表达式注入**——用户输入不再能篡改正在编译的模式
- **翻译更新脚本中的原型污染函数**——对象键现在被安全地构建
- **任务队列测试中的不安全临时文件处理**
- **图片元数据查找中的文件系统竞态条件**——文件现在会在使用前进行原子性验证
- **日志注入**（CWE-117）——日志参数中的换行字符会被清除，用户输入无法伪造日志行
- **BMF 媒体探测中的命令注入加固**——二进制文件现在通过 `execFileSync` 配合显式参数调用，而不是使用 shell 字符串

每一项修复都附带回归测试，防止漏洞卷土重来。
