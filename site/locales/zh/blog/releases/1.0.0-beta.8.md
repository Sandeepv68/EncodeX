# EncodeX V1.0.0-beta.8

**发布日期：** 2026-11-20
**标签：** [`v1.0.0-beta.8`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8)

## 新功能

这是在 `1.0.0-beta.7` 基础上的一个修复版本。

- **更新可用事件** — 更新程序现在会将检测到的更新转发给渲染进程。生产环境的 IPC 校验检查的是 `asset.fileName`，而主进程发送的是 `asset.name/url/size`，因此该事件此前会被静默丢弃。
- **界面不再卡住** — **检查更新**现在会显示可用更新，而不再停留在“正在检查更新”。

beta.7 的对话框优化，以及 Copilot、MCP 2.x、remux/demux、视频滤镜和 mux 队列的较大变更，见 [1.0.0-beta.7 版本](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7)和 [1.0.0-beta.6 版本](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6)。

## 升级

可通过应用内的 **Check for Updates** 操作进行更新，或从 [GitHub release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8) 下载安装程序。与往常一样，转换始终在你的本地机器上完成——无需账户、无需上传、无水印。
