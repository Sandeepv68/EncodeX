# 转换配置文件

我们刚刚发布了 EncodeX 中最受期待的功能之一：**转换配置文件**。无需每次转换文件时手动选择编解码器、码率、质量设置和容器格式，你现在可以从 140 多个预配置的预设中选择，让一切自动完成。

## 什么是转换配置文件？

转换配置文件是一种保存的编码配置。它告诉 EncodeX 具体使用哪个视频编解码器、音频编解码器、码率、质量级别、分辨率、像素格式和容器——一切只需一键。

可以把它想象成一个食谱。不需要自己称量每种食材，选一个食谱就全部就绪。

## 包含内容

140 多个内置配置文件分为 8 个类别：

### Web 与社交

为实际发布平台优化的预设：

- **YouTube** — 480p 到 4K，包含 H.264、H.265 和 AV1 变体
- **Instagram** — Reels、Stories 和动态帖子，使用正确的宽高比和编解码器
- **TikTok** — 竖版视频预设，针对快速上传和良好质量调校
- **Facebook** — 视频帖子和广告
- **X (Twitter)** — 短视频，考虑文件大小限制

### 设备

针对特定硬件匹配的预设：

- **Apple** — iPhone、iPad、Mac、Apple TV（H.264 和 HEVC）
- **Android** — 手机和平板预设
- **游戏主机** — PlayStation、Xbox 和 Nintendo Switch 兼容格式

### 视频编解码器

当你知道想要哪个编码器时的编解码器特定配置文件：

- H.264、H.265/HEVC、VP8、VP9、AV1
- MPEG-4、MPEG-2、Theora

### 专业

广播和后期制作格式：

- **ProRes** — 422 LT、422、422 HQ、4444、4444 XQ
- **DNxHD / DNxHR** — 多种分辨率和质量层级
- **FFV1** — 无损归档编解码器
- **XDCAM / XAVC** — Sony 广播格式

### 流媒体

自适应比特率流媒体预设：

- **HLS** — HTTP Live Streaming，可配置分段时长
- **DASH** — MPEG-DASH 输出

### 音频

纯音频转换预设：

- MP3（128k、192k、320k）
- AAC（128k、192k、256k）
- FLAC（无损）
- Opus、WAV 等

### 图片

图片格式转换：

- JPEG、PNG、WebP、AVIF，带质量控制

### 高级

面向高级用户：

- 原始 FFmpeg 参数预设
- 自定义 FFmpeg 直通
- 用于测试的空输出

## 如何使用配置文件

1. 打开**转换**页面（或**批量队列**）
2. 在设置区域顶部找到**配置文件选择器**
3. 按类别浏览或按名称搜索
4. 点击一个配置文件——所有编码字段自动填入
5. 按需调整任何设置，然后点击转换

配置文件选择器为每个配置文件显示类别图标徽章，让你能快速区分 YouTube 预设和 ProRes 预设。

## 自定义配置文件

如果内置目录不能覆盖你的具体用例，可以创建自己的：

1. 手动配置你的编码设置
2. 点击配置文件选择器中的保存按钮
3. 起个名字并选择类别
4. 你的自定义配置文件会出现在内置配置文件旁边

自定义配置文件保存在本地，在会话之间持续存在。你可以随时编辑或删除它们。（内置配置文件是锁定的——可以使用但不能修改。）

## 最近使用

EncodeX 记住你最近应用的 5 个配置文件，让你最常用的工作流始终只需一键。不必在总是使用相同两个预设时浏览类别。

## 批量队列支持

配置文件在批量队列中同样有效。应用配置文件为新任务设置编码选项，或者在自定义各个批量条目之前将其作为起点。

## 内部原理

每个配置文件映射到一个 `ConversionProfile` 对象，存储：

- 容器格式和输出扩展名
- 视频和音频编解码器选择
- 码率、CRF 和质量设置
- 缩放、像素格式和 FPS
- 高级 FFmpeg 参数（`extraArgs` 和 `inputArgs`）用于专业格式

当你应用配置文件时，EncodeX 将这些值写入转换表单。高级配置文件可以直接将原始 FFmpeg 标志传递给编码器——这就是我们支持 ProRes 配置文件选择和 HLS 分段配置等方式。

配置文件是 GUI 功能——CLI 继续使用显式标志（`--video-codec`、`--audio-codec` 等），为脚本和自动化提供最大灵活性。
