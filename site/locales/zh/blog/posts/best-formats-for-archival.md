# 存档视频的最佳格式：让您的媒体保存数十年

视频文件会逐渐过时 —— 不是像照片那样褪色，而是像技术那样日新月异。今天可用的编解码器，十年后您的播放器可能就不再支持。看似永久的格式，也可能被封锁在您无法再访问的专有编码器背后。存档视频的意义在于做出选择，让您的媒体尽可能长久地保持可播放和忠实还原。

## 为什么存档格式的选择很重要

每当你转码一段视频 —— 从一个编解码器重新编码到另一个 —— 你都会丢失一点信息。对于 H.264 或 H.265 等有损编解码器，每一次转码都会引入细微的劣化。对于无损编解码器，信息不会丢失，但文件会大得多。

存档的目标是以一种能在数十年内保持准确的方式存储原始数据。这意味着要选择开放、文档完善且不太可能过时的格式。

## 存档编解码器

### FFV1

FFV1（FF Video Codec 1）是存档视频的黄金标准。它是开源的、无损的（在较低设置下接近无损），并且专为长期保存而设计。包括 Internet Archive 和 Library of Congress 在内的大型档案机构都使用 FFV1 来保存它们的视频收藏。

FFV1 支持多线程、错误恢复能力和广泛的像素格式。它通常存储在 Matroska (`.mkv`) 容器中，该容器本身也是开放且文档完善的。

**何时使用：** 存档母版副本、电影保存、任何需要文件多年保持原样的情况。

### ProRes

Apple 的 ProRes 系列广泛用于专业视频制作。它是一种有损编解码器，但质量水平非常高，在正常观看下损失几乎不可见。ProRes 是许多视频编辑器的默认交换格式 —— 如果你给别人一个 ProRes 文件，他们几乎可以在任何编辑软件中使用它。

EncodeX 通过 FFmpeg 支持 ProRes，提供从 Proxy（低带宽编辑）到 4444 XQ（视觉无损）的各种配置档。

**何时使用：** 用于编辑的工作副本、制作流程中的中间文件、与使用 Final Cut Pro 或 DaVinci Resolve 的剪辑师共享文件。

### HuffYUV

HuffYUV 是一种无损编解码器，比 FFV1 更简单、更快。它生成的文件较大，但编码和解码速度快，因此在编辑工作流程中作为中间格式非常有用 —— 当你需要无损质量但又不想承担 FFV1 的计算开销时。

**何时使用：** 编辑期间快速中间编码、录屏存档、编码/解码速度与质量同等重要的情况。

### 未压缩的 YUV

最直接的存档格式：完全不做压缩。每个像素都按原样存储。文件体积巨大 —— 一分钟的 1080p 片段可能达到数 GB —— 但数据完全未经改动。

**何时使用：** 绝对最高的保真度存档、科学或医学影像，或作为质量比较的参考。

## 无损复制：不是存档，而是保存

如果你的源文件已经采用不错的编解码器（比如 MP4 容器中的 H.264），而你只是为了兼容性需要更换容器，你可以进行无损复制 —— 不重新编码、不损失质量、近乎即时的转换：

```bash
encodex convert in.mkv -o out.mp4 --video-codec copy --audio-codec copy
```

这会原样保留原始数据流。就「长期保存」的意义而言，这不算存档，但对于在不劣化的情况下维持兼容性来说非常理想。

## 实用的存档策略

1. **保留你的原始文件。** 转换后不要删除源录像。
2. **创建无损存档副本** —— 对任何你想长期保存的内容，使用 FFV1/MKV 或 ProRes。
3. **创建有损交付副本** —— 使用 H.264/H.265，用于分享、上传或日常观看。
4. **记录你的工作流程。** 注明所使用的编解码器、设置和工具 —— 这有助于未来的存档人员了解他们处理的是什么内容。
