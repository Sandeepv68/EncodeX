## 为什么 FFmpeg 很强大却令人望而生畏

FFmpeg 几乎可以用媒体文件做任何事。需要把 4K MKV 转成适合手机的轻量 MP4？FFmpeg 可以。想把 YouTube 视频的音频提取为高质量 FLAC？FFmpeg 也能处理。需要批量压缩 OBS 录制文件而不产生明显的质量损失？FFmpeg 都能搞定。

问题不在 FFmpeg 的能力——而在它的界面。要转换一个视频，你可能需要输入类似这样的命令：

```bash
ffmpeg -i input.mkv -c:v libx264 -crf 23 -c:a aac output.mp4
```

这已经是一个相对简单的命令，但对大多数人来说仍然令人困惑。再加上硬件加速、字幕轨或批量处理，命令就会长成一段段落。对于不是开发者或系统管理员的人来说，命令行就像一扇通往强大房间的锁着的门。

这正是[视频转换器](/zh/video-converter)图形界面要填补的差距。你不应该只是为了转换一个视频而学习一个接近编程的工具。
