# 什么是 FFmpeg？

**FFmpeg** 是一款免费的开源软件库和命令行工具，是几乎所有视频和音频转换背后看不见的引擎。如果你曾转换过视频，很可能使用的是基于 FFmpeg 构建的工具——包括 **EncodeX**。

## 用一句话概括 FFmpeg

> FFmpeg 是音视频领域的瑞士军刀——一种能读取几乎所有媒体文件、并以几乎任何其他格式写入的软件。

## FFmpeg 能做什么？

FFmpeg 可以：

- 在**数百种格式之间转换视频和音频**
- **压缩文件**使其变小
- **剪切、裁剪和拼接**片段
- 从视频中**提取音频**
- **调整大小、重新采样**并添加效果
- **流式传输媒体**等等

它强大得惊人——而这正是它的缺点所在。

## 问题：FFmpeg 是命令行工具

FFmpeg 通过输入命令来操作。例如，要转换一个视频，你需要输入类似这样的内容：

```bash
ffmpeg -i input.mkv -c:v libx264 -crf 18 -c:a aac output.mp4
```

如果这对你来说像一门外语，你并不孤单。这正是**FFmpeg GUI** 存在的意义。

## 关于编解码器与容器的简短说明

你会常听到两个术语：

- **容器**——装视频和音频轨道的"外包装"。常见：**MP4**、**MKV**、**MOV**、**AVI**。
- **编解码器**——压缩视频或音频的方法。常见：**H.264**、**H.265/HEVC**、**AV1**。

单个 MP4 文件内部可以使用 H.264、H.265 或 AV1。理解两者的区别有助于你选择合适的输出——而 EncodeX 的预设建议会替你处理这个选择。
