## WAV vs MP3: Qual devo usar?

- Escolha **WAV** quando precisar de áudio sem compressão — para editar, masterizar ou arquivar
- Escolha **MP3** quando o tamanho importar mais que a fidelidade — para celulares, compartilhamento e audição casual

Use o EncodeX para extrair ambos: guarde o master em WAV e converta para MP3 quando estiver pronto para compartilhar.

## FAQ

**O som WAV é melhor que o MP3?** WAV não é comprimido, então mantém o áudio original como foi decodificado, enquanto o MP3 descarta alguns dados para economizar espaço. Se o áudio de origem já for com perdas (como a maioria dos áudios de vídeo), o WAV não recupera os detalhes perdidos. Para editar e arquivar, WAV é a escolha segura.

**Extrair WAV cria arquivos enormes?** Sim — o WAV é bem maior que o MP3, já que não é comprimido. Esse é o preço do áudio sem compressão.

**Posso extrair WAV de vários vídeos em lote?** Sim. O EncodeX pode extrair o áudio de uma pasta inteira de vídeos de uma só vez.
