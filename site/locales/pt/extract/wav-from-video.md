- **Pronto para estúdio** — ideal para Audacity, Ableton e editores
- **Modo lote** — extraia WAV de uma pasta inteira de vídeos de uma vez

## WAV vs MP3: Qual devo usar?

- Escolha **WAV** quando precisar de áudio sem perdas — para editar, masterizar ou arquivar
- Escolha **MP3** quando o tamanho importar mais que a fidelidade — para celulares, compartilhamento e audição casual

Use o EncodeX para extrair ambos: guarde o master em WAV e converta para MP3 quando estiver pronto para compartilhar.

## FAQ

**O som WAV é melhor que o MP3?** WAV não é comprimido, então é o verdadeiro áudio original — o MP3 descarta alguns dados para economizar espaço. Para editar e arquivar, WAV é a escolha segura.

**Extrair WAV cria arquivos enormes?** Sim — cerca de 10 MB por minuto de áudio estéreo de 16 bits/48 kHz. Esse é o preço da qualidade sem perdas.

**Posso extrair WAV de vários vídeos em lote?** Sim. O EncodeX pode extrair o áudio de uma pasta inteira de vídeos de uma só vez.
