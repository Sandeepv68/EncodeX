# EncodeX para Linux

**EncodeX para Linux** traz todo o poder do **FFmpeg** para desktops Linux por trás de uma interface amigável — sem necessidade de linha de comando. É gratuito, de código aberto e roda a 100 % na sua máquina.

## Uma interface gráfica gratuita do FFmpeg para Linux

Os usuários do Linux recebem exatamente o que esperam de uma ferramenta gratuita:

- **Versão AppImage** — roda na maioria das distribuições sem instaladores
- **Código aberto (MIT)** — inspecione o código ou compile você mesmo
- **Aceleração por hardware VAAPI** — codificações rápidas com GPUs da AMD, Intel e NVIDIA
- **CLI sem interface gráfica** — programe conversões para servidores e automação
- **Offline e privado** — seus vídeos nunca saem da sua máquina
