# EncodeX para Mac

**EncodeX para Mac** traz todo o poder do **FFmpeg** para o macOS por trás de uma interface amigável — sem necessidade de linha de comando. É gratuito, de código aberto e roda a 100 % no seu Mac.

## Uma interface gráfica gratuita do FFmpeg para macOS

Os usuários do Mac escolhem EncodeX porque ele é projetado de acordo com a forma de trabalhar do Mac:

- **Pronto para Apple Silicon** — uma versão nativa para Apple Silicon com suporte a Intel
- **Aceleração por hardware VideoToolbox** — codificações rápidas nos chips da série M
- **Arrastar e soltar** — nenhum conhecimento de terminal necessário
- **Pastas em lote** — processe centenas de arquivos de uma vez
- **Offline e privado** — seus vídeos nunca saem do seu Mac

**EncodeX funciona em Macs com Apple Silicon?** Sim, há uma versão dedicada para Apple Silicon que roda nativamente e usa o codificador por hardware VideoToolbox.

**EncodeX envia meus vídeos?** Não. Toda a conversão ocorre localmente no seu Mac.
