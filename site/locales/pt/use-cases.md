## Para quem é o EncodeX?

**Criadores de conteúdo** — comprima para upload, extraia áudio, converta formatos.
**Estudantes** — transforme aulas gravadas em notas de áudio, apare gravações longas.
**Podcasters** — extraia trilhas de áudio, comprima para distribuição.
**Desenvolvedores** — conversão em lote, scripts com a CLI, análise de mídia com a API.
**Todos os outros** — se "formato de arquivo" parece jargão, o EncodeX foi feito para você.
