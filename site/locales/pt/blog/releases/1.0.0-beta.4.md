# EncodeX V1.0.0-beta.4

**Lançado:** 2026-09-20
**Tag:** [`v1.0.0-beta.4`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.4)

## Novidades

Esta versão tem duas partes: várias funcionalidades totalmente novas e uma rodada séria de reforço de segurança. Corrija um clipe gravado de lado sem perder qualidade, deixe um assistente de IA controlar suas conversões via MCP e fique tranquilo sabendo que a linha de comando e o tratamento de arquivos foram auditados e protegidos.

---

## Rotação e espelhamento

A ferramenta corretiva mais pedida chegou. **Rotação e espelhamento** permite girar vídeos e fotos em **90°, 180° ou 270° no sentido horário** e espelhá-los **horizontal ou verticalmente** — na página de Converter e na fila de lotes.

Corrigir um clipe de lado leva segundos e, quando a saída é MP4, MOV ou MKV no modo stream-copy (sem perdas), a rotação é salva como metadados de exibição padrão — **nada é re-codificado** e a qualidade fica intacta. Para outros formatos, ou quando você espelha a imagem, o EncodeX aplica em vez disso uma cadeia de filtros FFmpeg eficiente.

[Leia o guia completo de rotação](/blog/releases/rotate-and-mirror-videos)

## Servidor MCP integrado: deixe a IA controlar suas conversões de mídia

O EncodeX agora pode atuar como um **servidor de Model Context Protocol (MCP)**, para que assistentes de IA — Claude Desktop, Claude Code, Cursor, VS Code e qualquer cliente compatível com MCP — possam converter vídeos, extrair áudio, comprimir imagens, cortar clipes e gerenciar trabalhos em lote através do EncodeX, usando apenas um pedido em linguagem natural.

- **19 ferramentas** em conversão, inspeção, gerenciamento de trabalhos e paridade com a GUI
- **3 recursos** (`encodex://profiles`, `encodex://capabilities`, `encodex://codecs`) para descoberta de capacidades
- **4 modelos de prompts** para as tarefas mais comuns
- **Dois transportes**: um servidor stdio autônomo `encodex --mcp` e um servidor HTTP loopback integrado para o modo GUI
- **Privado por design**: apenas loopback, token bearer opcional, encerramento limpo e zero uploads — tudo roda localmente

As conversões são assíncronas, então uma renderização longa nunca congela a conversa — seu assistente inicia o trabalho, recebe um ID e consulta ou cancela depois.

## Reforço de segurança

Um lote de alertas do CodeQL e achados de auditoria foram corrigidos e travados com testes de regressão:

- **Injeção de expressão regular** na análise da saída da CLI — a entrada do usuário não pode mais alterar o padrão que está sendo compilado
- **Função de poluição de protótipo** no script de atualização de traduções — as chaves de objetos agora são construídas com segurança
- **Tratamento inseguro de arquivos temporários** nos testes da fila de trabalhos
- **Condição de corrida no sistema de arquivos** na busca de metadados de imagens — os arquivos agora são verificados atomicamente antes do uso
- **Injeção em logs** (CWE-117) — caracteres de quebra de linha são sanitizados nos argumentos de log para que a entrada do usuário não possa forjar linhas de log
- **Proteção contra injeção de comandos** na sonda de mídia BMF — o binário agora é invocado via `execFileSync` com argumentos explícitos em vez de uma string de shell

Cada correção sai com um teste de regressão para impedir que as vulnerabilidades voltem.

## Casos de uso e atualizações do site

- **Páginas de casos de uso ampliadas** em todas as 7 versões de idioma, com fluxos de trabalho reais em vez de listas de recursos
- **Refatoração de código reutilizável** — utilitários compartilhados (como a nova função `clamp`) foram extraídos em todo o processo principal para um código mais limpo e testável
- **Fluxo de sincronização do wiki adicionado** — o GitHub Wiki agora é mantido em sincronia automaticamente a partir da pasta `wiki/`
- **Documentação das novas funcionalidades** — páginas de referência de rotação e MCP adicionadas em todos os idiomas

## Ferramentas de desenvolvimento

- **Cobertura E2E ampliada e estabilizada** para a fila de lotes e os fluxos de conversão
- **Testes de fumaça MCP adicionados ao CI** para que regressões do servidor sejam detectadas antes do lançamento
