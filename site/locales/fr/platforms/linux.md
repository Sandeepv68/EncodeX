# EncodeX pour Linux

**EncodeX pour Linux** apporte toute la puissance de **FFmpeg** aux postes de travail Linux derrière une interface conviviale — sans ligne de commande nécessaire. C'est gratuit, open source et fonctionne à 100 % sur votre machine.

## Une interface graphique gratuite de FFmpeg pour Linux

Les utilisateurs de Linux obtiennent exactement ce qu'ils espèrent d'un outil gratuit :

- **Version AppImage** — fonctionne sur la plupart des distributions sans installateur
- **Open source (MIT)** — inspectez le code ou compilez-le vous-même
- **Accélération matérielle VAAPI** — encodages rapides sur les GPU AMD et Intel ; les GPU NVIDIA utilisent NVENC
- **CLI** — scriptez des conversions et l'automatisation
- **Hors ligne et privé** — vos vidéos ne quittent jamais votre machine

[Téléchargez EncodeX gratuitement](/fr/download) — récupérez l'**AppImage Linux** sur la page de téléchargement (voir **Autres plateformes**). Rendez-le exécutable et lancez-le :
