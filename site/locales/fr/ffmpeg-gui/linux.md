# Interface FFmpeg pour Linux

Les utilisateurs Linux méritent aussi une excellente **interface FFmpeg**. **EncodeX** est un **front-end FFmpeg** gratuit et open source qui fonctionne sur Linux en AppImage — sans tracas de paquets, sans ligne de commande.

## Pourquoi EncodeX sur Linux ?

EncodeX offre aux utilisateurs Linux une **interface FFmpeg** complète avec la même expérience propre sur toutes les plateformes :

- **Convertissez** la vidéo et l'audio — MP4, MKV, AVI, MOV, WebM, MP3, FLAC, WAV et plus
- **Compressez** des vidéos pour réduire la taille tout en gardant la qualité
- **Coupez** des clips avec une timeline visuelle
- **Extrayez** l'audio d'une vidéo et enregistrez-le en MP3
- **Traitez par lots** des dossiers automatiquement

### Rapide sur votre matériel

EncodeX prend en charge l'**accélération matérielle** sur Linux via **VAAPI**, ainsi que NVENC sur GPU NVIDIA — l'encodage utilise donc votre matériel au lieu de vous faire attendre.

Vous cherchez **ffmpeg gui linux** ? EncodeX est open source (MIT) et réellement gratuit :
