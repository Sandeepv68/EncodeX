# Compresser des vidéos MKV

## Pourquoi compresser des fichiers MKV ?

Le MKV est un conteneur favori pour la vidéo haute qualité — c'est aussi pourquoi il devient gros :

- **Gros remux** — les rips Blu-ray intacts peuvent dépasser la dizaine de gigaoctets
- **Espace d'archivage** — les collections remplissent vite les disques
- **Partage** — les fichiers MKV sont trop lourds pour de nombreuses applications de chat et de messagerie
- **Streaming** — les serveurs médias fonctionnent mieux avec des débits raisonnables
