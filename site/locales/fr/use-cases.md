## Pour qui est fait EncodeX ?

**Créateurs de contenu** — compressez pour la mise en ligne, extrayez l'audio, convertissez les formats.
**Étudiants** — transformez vos cours enregistrés en notes audio, rognez les enregistrements longs.
**Podcasters** — extrayez les pistes audio, compressez pour la diffusion.
**Développeurs** — conversion par lots, scripts avec la CLI, analyse des médias avec l'API.
**Tous les autres** — si « format de fichier » sonne comme du jargon, EncodeX a été fait pour vous.
