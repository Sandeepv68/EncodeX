# Was ist das beste Videoformat? Ein Entscheidungsrahmen

Fragen Sie fünf Personen nach dem „besten" Videoformat und Sie erhalten fünf verschiedene Antworten — denn die richtige Antwort hängt vollständig davon ab, was Sie mit der Datei vorhaben. Konvertieren Sie einen Film für Ihr Handy, ist eine 5-GB-MKV die falsche Wahl; archivieren Sie Heimvideos für immer, könnte genau dieses MKV genau richtig sein.

Statt Spezifikationen auswendig zu lernen, verwenden Sie diesen Entscheidungsrahmen: **Passen Sie das Format an das Ziel an.** So denken Sie in verständlicher Sprache darüber nach.

## Die zwei Dinge, die alle verwechseln

Jede Videodatei besteht aus zwei unabhängigen Teilen:

- **Der Container** — die „Box", die alles enthält: `mp4`, `mkv`, `mov`, `webm`, `avi`. Der Container ist das, was Sie als Dateiendung sehen.
- **Der Codec** — wie das Video in der Box komprimiert wird: `H.264`, `H.265/HEVC`, `AV1`, `VP9`.

Sie können den Codec über die Dateiendung nicht vollständig steuern — eine `.mkv`- und eine `.mp4`-Datei können beide dasselbe H.265-Video enthalten. Deshalb geht unsere vollständige [Anleitung zum richtigen Format](/de/learn/what-format-to-use) jedes Format einzeln durch.

## Entscheidung 1: Wer oder was wird das abspielen?

Beginnen Sie hier. Das Gerät am Ende entscheidet alles.

| Ziel | Container | Zu verwendender Codec |
|-------------|-----------|--------------|
| Ihr Handy, TV, Web, E-Mail, Gruppenchat | MP4 | H.264 (sicherste Wahl) oder H.265 |
| Ein Videobearbeitungsprogramm | MP4 oder MOV | H.264 |
| Archivierung / langfristige Aufbewahrung | MKV | H.265 oder AV1 (jeder Codec ist in Ordnung) |
| Das Web / Ihre eigene Website | MP4 oder WebM | H.264 + AV1 als Fallback |
| Ihr eigener Streaming-Server | MP4 | H.265 mit recht hoher Bitrate |

Die verbindende Regel: **Wählen Sie für alles, das „einfach abspielbar" sein muss, MP4.** Es ist das einzige Format, auf das sich jedes Gerät, jeder Browser und jede Plattform einigen kann.

## Entscheidung 2: Benötigen Sie eine kleinere Datei?

Die Dateigröße ist eine Entscheidung für sich, getrennt vom Format. Eine 4K-H.264-MP4-Datei kann immer noch riesig sein. Wenn die Größe eine Rolle spielt — beim Verschicken per E-Mail, beim Hochladen in eine Messaging-App oder beim Sparen von Speicherplatz — wählen Sie einen *Komprimierungsgrad*, keinen Container:

- **H.265/HEVC ist 2026 der Sweet Spot.** Etwa halb so groß wie H.264 bei gleicher Qualität. Die Wiedergabeunterstützung ist inzwischen ausgezeichnet.
- **AV1 bietet die beste Qualität pro Byte**, codiert aber langsamer und ältere Geräte spielen es möglicherweise nicht ab.
- **H.264 bleibt am kompatibelsten** — wählen Sie es, wenn Sie sicher sein müssen, dass *alles* Ihre Datei abspielt.

## Entscheidung 3: Was ist die Quelle?

- **Eine Bildschirmaufnahme, ein Handyclip, ein Download oder eine Kameradatei** — meist nur neu verpackt, selten neu codiert. Ist sie bereits MP4-kompatibel, ist die Konvertierung nahezu sofort und verlustfrei.
- **Eine alte AVI-Datei von 2008** — darin steckt wahrscheinlich MPEG-4 ASP oder H.264; EncodeX codiert sie in modernes H.264 neu, damit sie überall abgespielt wird.
- **Ein Blu-ray-MKV-Remux** — oft bereits H.265; die Konvertierung zu MP4 ist ein schneller Container-Tausch ohne Qualitätsverlust.

## Häufig gestellte Fragen

### Ist MP4 immer das beste Videoformat?

Für Teilen und Wiedergabe: ja — es ist der weltweit kompatibelste Container. Es hat Grenzen: keine Menüstruktur und eine schwächere Unterstützung für ältere Untertitelformate als MKV, aber für 99 % der Alltagsdateien ist MP4 die richtige Wahl.

### MP4 oder MKV für die Speicherung?

Wenn Sie archivieren, ist MKV der flexiblere Container (mehrere Audiospuren, umfangreiche Untertitel). Wenn Sie die Datei später weniger technisch versierten Freunden oder Familienmitgliedern übergeben möchten, konvertieren Sie sie zuerst in MP4.

### Entscheidet das Format über die Qualität?

Nein. Die Qualität wird durch die **Codec-Einstellungen** (Bitrate, Auflösung, Encoder) entschieden, nicht durch die Dateiendung. Ein MKV ohne Neucodierung in MP4 umzuverpacken verliert null Qualität; bei aggressiver Komprimierung beim Neucodieren geht die Qualität verloren.

### Sollte ich alles in H.265 konvertieren?

Nicht alles — H.265 kann langsamer codieren und ein paar alte Geräte spielen es nicht ab. Verwenden Sie es für Ihre eigene Sammlung, bei der Sie den Player kontrollieren, und H.264 für alles, was Sie in die Welt hinausschicken.
