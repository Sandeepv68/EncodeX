# EncodeX V1.0.0-beta.8

**Veröffentlicht:** 2026-11-20
**Tag:** [`v1.0.0-beta.8`](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8)

## Was ist neu

Dies ist eine kleine Fehlerbehebungs-Version auf Basis von `1.0.0-beta.7`.

- **Update-Verfügbarkeitsereignis** — der Updater leitet ein erkanntes Update jetzt an den Renderer weiter. Der IPC-Guard in der Produktion prüfte `asset.fileName`, während main `asset.name/url/size` sendet, sodass das Ereignis still verworfen wurde.
- **Kein hängenbleibendes UI mehr** — **Nach Updates suchen** zeigt jetzt das verfügbare Update anstatt auf „Updates werden geprüft" zu bleiben.

Die Dialog-Verfeinerung aus beta.7 sowie die größeren Änderungen an Copilot, MCP 2.x, Remux/Demux, Videofiltern und Mux-Warteschlange findest du im [Release 1.0.0-beta.7](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.7) und im [Release 1.0.0-beta.6](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.6).

## Upgrade

Aktualisiere über die Aktion **Nach Updates suchen** in der App oder lade die Installationsdateien aus dem [GitHub-Release](https://github.com/Sandeepv68/EncodeX/releases/tag/v1.0.0-beta.8) herunter. Wie immer bleibt die Konvertierung lokal auf deinem Rechner — kein Konto, kein Upload und kein Wasserzeichen.
