# EncodeX für Windows

**EncodeX für Windows** bringt die volle Leistung von **FFmpeg** hinter einer freundlichen grafischen Oberfläche — ohne Kommandozeile. Es ist kostenlos, Open Source und läuft zu 100 % auf Ihrem PC.

## Eine kostenlose FFmpeg-Oberfläche für Windows 10 und 11

Windows-Nutzer lieben EncodeX, weil es einfach funktioniert:

- **Ein-Klick-Installation** — ein Standard-`.exe`-Installationsprogramm, ohne Admin-Komplikationen
- **Volle FFmpeg-Leistung** — konvertieren, komprimieren, schneiden und extrahieren ohne einen einzigen Befehl einzugeben
- **NVIDIA-, Intel- und AMD-Hardwarebeschleunigung** — NVENC, Quick Sync und AMF für schnelle Encodierungen
- **Batch-Ordner** — verarbeiten Sie Hunderte von Dateien auf einmal
- **Offline & privat** — Ihre Videos verlassen nie Ihren PC

## Häufig gestellte Fragen

**Funktioniert EncodeX unter Windows 11?** Ja, EncodeX unterstützt Windows 11 und Windows 10 vollständig (64-Bit und ARM64).

**Warum zeigt Windows eine Warnung „Windows protected your PC"?** EncodeX-Releases tragen keine Code-Signatur, daher kann SmartScreen den Herausgeber nicht bestätigen und zeigt „Unbekannter Herausgeber". Die Warnung ist bei einem unsignierten Build erwartet. Klicken Sie auf **Weitere Infos** und dann auf **Trotzdem ausführen**.

**Ist EncodeX für Windows wirklich kostenlos?** Ja — 100 % kostenlos, Open Source (MIT), keine Werbung, keine Wasserzeichen, keine kostenpflichtigen Stufen.

**Lädt EncodeX meine Videos hoch?** Nein. Alle Konvertierung erfolgt lokal auf Ihrem PC.

**Ist die Windows-FFmpeg-Oberfläche einfach für Anfänger?** Absolut. Wenn Sie Drag-and-Drop können, können Sie mit EncodeX konvertieren.
