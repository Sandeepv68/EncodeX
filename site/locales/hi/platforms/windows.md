# EncodeX Windows के लिए

**EncodeX Windows के लिए** **FFmpeg** की संपूर्ण शक्ति को एक मित्रवत ग्राफ़िकल इंटरफ़ेस के पीछे रखता है — कमांड लाइन की आवश्यकता नहीं। यह मुफ़्त है, ओपन-सोर्स है, और आपके पीसी पर 100% चलता है।

## Windows 10 और 11 के लिए एक मुफ़्त FFmpeg GUI

Windows उपयोगकर्ताओं को EncodeX बहुत पसंद है क्योंकि यह बस काम करता है:

- **एक-क्लिक इंस्टॉल** — एक मानक `.exe` इंस्टॉलर, बिना एडमिन परेशानी के
- **पूरी FFmpeg शक्ति** — बिना एक भी कमांड टाइप किए कन्वर्ट, संपीड़ित, काटें और एक्सट्रैक्ट करें
- **NVIDIA और Intel हार्डवेयर एक्सेलरेशन** — तेज़ एन्कोडिंग के लिए NVENC और Quick Sync
- **बैच फ़ोल्डर** — एक साथ सैकड़ों फ़ाइलें प्रोसेस करें
- **ऑफ़लाइन और निजी** — आपके वीडियो कभी आपके पीसी से बाहर नहीं जाते
