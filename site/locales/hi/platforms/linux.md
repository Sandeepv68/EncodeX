# EncodeX Linux के लिए

**EncodeX Linux के लिए** **FFmpeg** की संपूर्ण शक्ति को Linux डेस्कटॉप पर एक मित्रवत इंटरफ़ेस के पीछे लाता है — कमांड लाइन की आवश्यकता नहीं। यह मुफ़्त है, ओपन-सोर्स है, और आपकी मशीन पर 100% चलता है।

## Linux के लिए एक मुफ़्त FFmpeg GUI

Linux उपयोगकर्ताओं को एक मुफ़्त टूल से ठीक वही मिलता है जिसकी उन्हें उम्मीद होती है:

- **AppImage बिल्ड** — बिना इंस्टॉलर के अधिकांश डिस्ट्रीब्यूशन पर चलता है
- **ओपन-सोर्स (MIT)** — कोड का निरीक्षण करें या इसे स्वयं बिल्ड करें
- **VAAPI हार्डवेयर एक्सेलरेशन** — AMD, Intel और NVIDIA GPU के साथ तेज़ एन्कोडिंग
- **हेडलेस CLI** — सर्वर और ऑटोमेशन के लिए कन्वर्ज़न स्क्रिप्ट करें
- **ऑफ़लाइन और निजी** — आपके वीडियो कभी आपकी मशीन से बाहर नहीं जाते

## EncodeX Linux के लिए डाउनलोड करें

[EncodeX मुफ़्त में डाउनलोड करें](/hi/download) — डाउनलोड पेज से **Linux AppImage** प्राप्त करें (देखें **अन्य प्लेटफ़ॉर्म**)। इसे एग्ज़ीक्यूटेबल बनाएं और चलाएं:

```bash
chmod +x EncodeX.AppImage
./EncodeX.AppImage
```

## अक्सर पूछे जाने वाले प्रश्न

**क्या EncodeX Wayland का समर्थन करता है?** हाँ, ऐप X11 और Wayland दोनों सेशन पर चलता है।

**क्या मैं बिना डेस्कटॉप वाले Linux सर्वर पर EncodeX का उपयोग कर सकता हूँ?** हाँ — EncodeX में एक [CLI मोड](/hi/cli) शामिल है जो बिना डेस्कटॉप के कन्वर्ज़न स्क्रिप्ट करने के लिए है।

**क्या Linux के लिए EncodeX वास्तव में मुफ़्त है?** हाँ — 100% मुफ़्त, ओपन-सोर्स (MIT), कोई विज्ञापन नहीं, कोई खाता नहीं।
