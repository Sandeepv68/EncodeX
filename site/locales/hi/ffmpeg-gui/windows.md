# Windows के लिए FFmpeg GUI

## Windows पर EncodeX क्यों?

EncodeX Windows उपयोगकर्ताओं को एक पूर्ण **FFmpeg इंटरफ़ेस** देता है जो जटिल एन्कोडिंग कमांड को सरल बटन में बदल देता है:

- **वीडियो और ऑडियो कन्वर्ट करें** – MP4, MKV, AVI, MOV, WebM आदि दर्जनों फ़ॉर्मेट
- **वीडियो कंप्रेस करें** ताकि गुणवत्ता बनाए रखते हुए फ़ाइल का आकार घटे
- **क्लिप काटें** – विज़ुअल टाइमलाइन पर हैंडल खींचकर
- **वीडियो से ऑडियो निकालें** और MP3 के रूप में सहेजें
- **पूरे फ़ोल्डर को बैच में प्रोसेस करें**
