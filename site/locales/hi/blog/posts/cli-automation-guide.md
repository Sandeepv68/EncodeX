# EncodeX CLI के साथ मीडिया वर्कफ़्लो को कैसे ऑटोमेट करें

EncodeX मुख्य रूप से GUI-फ़र्स्ट एप्लिकेशन है, लेकिन इसमें एक पूरी कमांड-लाइन इंटरफ़ेस भी शामिल है जो डेस्कटॉप ऐप की हर चीज़ कर सकती है — और कुछ ऐसी चीज़ें भी जो वह नहीं कर सकता। अगर आप नियमित रूप से मीडिया फ़ाइलों पर काम करते हैं और स्क्रिप्ट बनाना, बैच ऑटोमेट करना या कन्वर्ज़न को किसी वर्कफ़्लो में जोड़ना चाहते हैं, तो CLI EncodeX को कुछ ऐसा बना देती है जिसे आप टर्मिनल, CI पाइपलाइन या शेड्यूल्ड टास्क से चला सकते हैं।

## CLI का उपयोग क्यों करें?

GUI एक बार की कन्वर्ज़न के लिए आदर्श है — फ़ाइल खींचें, प्रोफ़ाइल चुनें, हो गया। लेकिन जब आपके पास पचास वीडियो का फ़ोल्डर है, या आप एक स्क्रिप्ट चाहते हैं जो किसी डायरेक्टरी में आने वाली हर रिकॉर्डिंग को कंप्रेस करे, तो CLI आपको बिना विंडो खोले एन्कोड करने देती है।

सामान्य उपयोग के मामले:

- **बैच कन्वर्ज़न स्क्रिप्ट** — एक कमांड से फ़ोल्डर की सभी `.mov` फ़ाइलों को `.mp4` में बदलें।
- **ऑडियो निकालें** — पॉडकास्ट या आर्काइव के लिए वीडियो फ़ाइलों से ऑडियो अलग करें।
- **CI/CD पाइपलाइन** — स्वचालित बिल्ड के हिस्से के रूप में मीडिया आर्टिफ़ैक्ट को वैलिडेट या री-एन्कोड करें।
- **शेड्यूल्ड टास्क** — हर रात नई रिकॉर्डिंग को स्वचालित रूप से कंप्रेस करें।
- **अन्य टूल्स के साथ इंटीग्रेशन** — मीडिया जानकारी को मॉनिटरिंग सिस्टम या लॉगिंग पाइपलाइन में भेजें।

## शुरू कैसे करें

अगर आपने EncodeX (GUI) इंस्टॉल कर लिया है, तो CLI पहले से उपलब्ध है। एक टर्मिनल खोलें और चलाएं:

```bash
encodex convert --help
```

आपको विकल्पों की पूरी सूची दिखाई देगी। CLI GUI की क्षमताओं को दर्शाती है: ऐप द्वारा समर्थित हर फ़ॉर्मेट, कोडेक और प्रोफ़ाइल कमांड लाइन से भी उपलब्ध है।

इंस्टॉलेशन विकल्पों और सभी उपलब्ध कमांड के लिए [CLI डॉक्यूमेंटेशन](/hi/docs/cli) देखें।

## वीडियो कन्वर्ट करना

सबसे सामान्य ऑपरेशन फ़ॉर्मेट के बीच कन्वर्ज़न है। एक सरल कन्वर्ज़न:

```bash
encodex convert in.mov -o out.mp4
```

यह EncodeX की डिफ़ॉल्ट सेटिंग्स (MP4 कंटेनर में H.264 + AAC) का उपयोग करता है और एक ऐसी फ़ाइल बनाता है जो हर जगह काम करती है।

किसी विशिष्ट कोडेक या गुणवत्ता को टारगेट करने के लिए:

```bash
encodex convert in.mov -o out.mp4 --video-codec libx265 --crf 20
```

H.265 समान गुणवत्ता पर छोटी फ़ाइलें बनाता है। CRF 20 एक उच्च गुणवत्ता सेटिंग है; छोटे नंबर का मतलब बेहतर गुणवत्ता (और बड़ी फ़ाइलें) है।

## ऑडियो निकालना

बिना री-एन्कोड किए वीडियो से ऑडियो ट्रैक निकालें:

```bash
encodex extract-audio in.mp4 -o audio.mp3
```

डिफ़ॉल्ट आउटपुट 192k का MP3 है। किसी अलग फ़ॉर्मेट के लिए:

```bash
encodex extract-audio in.mp4 -o audio.wav --codec libopus
```

यह वीडियो रिकॉर्डिंग से पॉडकास्ट ऑडियो निकालने, ऑडियो प्रीव्यू बनाने या साउंडट्रैक को अलग से आर्काइव करने के लिए उपयोगी है।

## लॉसलेस ट्रांसकोडिंग

जब आपको वीडियो या ऑडियो डेटा को छुए बिना कंटेनर फ़ॉर्मेट बदलना हो (उदाहरण के लिए, डिवाइस कम्पैटिबिलिटी के लिए `.mkv` से `.mp4` में बदलना):

```bash
encodex convert in.mkv -o out.mp4 --video-codec copy --audio-codec copy
```

यह लगभग तुरंत हो जाता है क्योंकि कोई एन्कोडिंग नहीं होती — स्ट्रीम्स बस नए कंटेनर में रीमक्स हो जाते हैं। उस आर्किविस्ट के लिए बिल्कुल सही जो बिना क्वालिटी लॉस के अधिकतम कम्पैटिबिलिटी चाहता है।

## बैच कन्वर्ज़न

एक साथ कई फ़ाइलें कन्वर्ट करें:

```bash
encodex batch *.mov -o output/ --video-codec libx264 --crf 23
```

सभी मिलती-जुलती फ़ाइलें क्रम में प्रोसेस होती हैं। प्रत्येक इनपुट फ़ाइल `output/` डायरेक्टरी में एक संगत आउटपुट फ़ाइल बन जाती है, जिसका एक्सटेंशन `.mp4` में बदल जाता है।

## मीडिया जानकारी प्राप्त करना

कन्वर्ट करने से पहले, आप किसी फ़ाइल के कोडेक, रिज़ॉल्यूशन या बिटरेट की जाँच करना चाह सकते हैं:

```bash
encodex info in.mp4
```

यह फ़ाइल की स्ट्रीम्स का एक पढ़ने योग्य सारांश प्रिंट करता है। मशीन-रीडेबल आउटपुट के लिए:

```bash
encodex info in.mp4 --json
```

JSON आउटपुट स्क्रिप्ट में उपयोगी है जहाँ आपको फ़ाइल की प्रॉपर्टी के आधार पर निर्णय लेने होते हैं (उदाहरण के लिए, "केवल तभी री-एन्कोड करें जब वीडियो कोडेक पहले से H.264 न हो")।

## एग्ज़िट कोड और एरर हैंडलिंग

CLI सार्थक एग्ज़िट कोड लौटाती है ताकि स्क्रिप्ट सफलता या विफलता का पता लगा सकें:

| कोड | अर्थ |
|------|---------|
| 0 | सफल |
| 1 | सामान्य त्रुटि |
| 2 | अमान्य आर्गुमेंट |
| 3 | इनपुट फ़ाइल नहीं मिली |
| 4 | आउटपुट फ़ाइल पहले से मौजूद है (बदलने के लिए `--overwrite` का उपयोग करें) |

शेल स्क्रिप्ट में इनका उपयोग करके एरर को सही तरीके से हैंडल करें:

```bash
encodex convert in.mp4 -o out.mp4
if [ $? -eq 4 ]; then
  echo "Output exists — skipping."
fi
```

## सब कुछ जोड़ना

CLI को कंपोज़ेबल होने के लिए डिज़ाइन किया गया है। एक वास्तविक स्क्रिप्ट कुछ ऐसा कर सकता है:

1. `encodex info --json` का उपयोग करके फ़ोल्डर की सभी वीडियो फ़ाइलों की जाँच करें
2. 500 MB से बड़ी फ़ाइलों को फ़िल्टर करें
3. उन फ़ाइलों को CRF 23 पर एक छोटे H.264 MP4 में कन्वर्ट करें
4. परिणाम लॉग करें

[पूरी CLI रेफ़रेंस](/hi/docs/cli) हर ऑप्शन, फ़्लैग और एग्ज़िट कोड का दस्तावेज़ है।
