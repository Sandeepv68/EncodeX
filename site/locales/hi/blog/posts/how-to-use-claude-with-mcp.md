# Claude Desktop और Claude Code के साथ EncodeX MCP सर्वर कैसे उपयोग करें

EncodeX एक बिल्ट-इन MCP सर्वर (Model Context Protocol) के साथ आता है, जिसका मतलब है कि आप सादी भाषा में Claude Desktop या Claude Code से पूरी ऐप को चला सकते हैं। इंटरफ़ेस खोलकर मेन्यू में ढूँढने के बजाय पूछिए: *"इस MKV को मेरे फ़ोन के लिए MP4 में बदलिए"* — और असिस्टेंट EncodeX के लोकल FFmpeg इंजन से कन्वर्जन कर देगा।

सब कुछ आपके कंप्यूटर पर चलता है। फ़ाइलें कभी आपके डिवाइस से बाहर नहीं जातीं, कोई अकाउंट नहीं है और सब कुछ ऑफ़लाइन काम करता है।

## MCP सर्वर क्या है?

[MCP](https://modelcontextprotocol.io) एक ओपन स्टैंडर्ड है जो AI असिस्टेंट्स को असली एप्लिकेशनों के टूल इस्तेमाल करने देता है। EncodeX का सर्वर कन्वर्जन टूल्स का एक सेट देता है — `convert_media`, `extract_audio`, `compress_image`, `cut_video`, `batch_convert`, साथ ही `get_job` और `list_jobs` जैसे जॉब-ट्रैकिंग टूल — और रिसोर्सेज़ और प्रॉम्प्ट टेम्पलेट्स भी।

इसे FFmpeg के रिमोट कंट्रोल की तरह समझिए जिसे AI असिस्टेंट चला सकता है। असिस्टेंट टूल देखता है, तय करता है कि कौन-से कॉल करने हैं, और EncodeX लोकली एन्कोडिंग करता है।

## शुरुआत

EncodeX इंस्टॉल करें ([डाउनलोड](/hi/download)) — MCP सर्वर बिल्ट-इन है, कोई प्लग-इन नहीं चाहिए — और सुनिश्चित करें कि `encodex` आपके `PATH` में हो (EncodeX इंस्टॉल करने पर जुड़ जाता है)।

### विकल्प 1: Claude Desktop

**Claude Desktop → Settings → Developer → Edit Config** खोलिए और एक MCP सर्वर एंट्री जोड़िए:

```json
{
  "mcpServers": {
    "encodex": {
      "command": "encodex",
      "args": ["--mcp"]
    }
  }
}
```

फ़ाइल सेव करके Claude Desktop रीस्टार्ट करें। Claude के पास अब EncodeX के टूल्स की पहुँच होगी।

### विकल्प 2: Claude Code

अपने प्रोजेक्ट में टर्मिनल से:

```bash
claude mcp add encodex -- encodex --mcp
```

फिर Claude Code शुरू करके कन्वर्जन के लिए कहिए। `claude mcp list` से सर्वर पंजीकृत हुआ है यह जाँच सकते हैं।

## आपका पहला रिक्वेस्ट

कुछ सरल आज़माइए:

> `~/Desktop/vacation.mp4` को WhatsApp के लिए छोटे MP4 में बदलिए।

असिस्टेंट `convert_media` कॉल करता है, जॉब आपकी मशीन पर बैकग्राउंड में चलता है और Claude परिणाम बताता है। चूँकि कन्वर्जन एसिंक्रोनस होता है, EncodeX एक जॉब ID लौटाता है; असिस्टेंट प्रोग्रेस के लिए `get_job` पूछता है और पूरा होने पर ख़त्म करता है।

आप ऑडियो भी निकाल सकते हैं:

> `lecture.mov` का ऑडियो MP3 के रूप में निकालिए।

यह `extract_audio` टूल से मेल खाता है। या इमेज का पूरा फ़ोल्डर कंप्रेस कीजिए:

> `~/Pics` की सभी फ़ोटो को `~/Output` फ़ोल्डर में कंप्रेस कीजिए।

यह `compress_image` टूल है, सादी भाषा में चलाया गया।

## सर्वर को बिना इंटरफ़ेस चलाएँ

`encodex --mcp` स्टैंडअलोन stdio सर्वर शुरू करता है। यह stdout पर JSON-RPC बोलता है (प्रोटोकॉल मैसेज साफ़ रखते हुए) और सारा स्टेटस और लॉग stderr पर डालता है। प्रोसेस तब तक ज़िंदा रहता है जब तक stdin बंद न हो — यानी ठीक वही जो डेस्कटॉप ऐप्स को ऑन-डिमांड MCP सर्वर चलाने के लिए चाहिए।

एम्बेडेड HTTP सतह — लाइव कतार, प्रीव्यू, टाइमलाइन और सिस्टम टूल — के लिए GUI में **Settings → MCP Server** चालू करें और क्लाइंट को `http://127.0.0.1:8765/mcp` पर इंगित करें।

## बेहतर परिणामों के लिए टिप्स

- **स्पष्ट या एब्सोल्यूट पाथ दीजिए** — इससे असिस्टेंट सही फ़ाइलों को निशाना बना पाता है।
- **आउटपुट फ़ॉर्मैट बताइए** — "MP4 के रूप में", "MP3 में" — ताकि सही प्रोफ़ाइल चुनी जाए।
- **फ़ोल्डरों के लिए बैच इस्तेमाल करें** — EncodeX एक ही जॉब में कई फ़ाइलें बदल सकता है ([बैच ऑटोमेशन गाइड](/hi/blog/posts/mcp-batch-automation-guide))।
- **अनजाने ऑप्शन के लिए डॉक्स देखें** — पूरा टूल कैटलॉग [MCP फ़ीचर रेफ़रेंस](/hi/docs/features-reference#mcp-server) में है।

## अक्सर पूछे जाने वाले प्रश्न

### क्या EncodeX MCP सर्वर मुफ़्त है?

हाँ — यह मुफ़्त, ओपन-सोर्स (MIT) EncodeX ऐप में बिल्ट-इन है। कोई सब्सक्रिप्शन नहीं, कोई लाइसेंस कुंजी नहीं।

### क्या `encodex --mcp` के लिए GUI खुला होना चाहिए?

नहीं। स्टैंडअलोन सर्वर बिना GUI के चलता है। एम्बेडेड HTTP सर्वर (Settings → MCP Server) वैकल्पिक सतह है जो ऐप के अंदर कतार और प्रीव्यू टूल के लिए चलती है।

### क्या MCP मेरी फ़ाइलें अपलोड करता है?

नहीं। EncodeX सब कुछ लोकली प्रोसेस करता है। MCP सर्वर उसी लोकल FFmpeg इंजन को चलाता है जैसा GUI — कोई अपलोड नहीं, कोई क्लाउड नहीं, कोई अकाउंट नहीं।

### कौन-से असिस्टेंट जुड़ सकते हैं?

कोई भी MCP-संगत क्लाइंट। यह गाइड Claude Desktop और Claude Code को कवर करता है; यही कॉन्फ़िगरेशन पैटर्न [Cursor और VS Code](/hi/blog/posts/cursor-and-vscode-mcp-workflows) में काम करता है।
