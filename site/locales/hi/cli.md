# EncodeX CLI

रोज़मर्रा के उपयोगकर्ताओं के लिए काफ़ी सरल। डेवलपर्स के लिए काफ़ी शक्तिशाली। **EncodeX** सिर्फ़ एक GUI नहीं है — वही FFmpeg इंजन **EncodeX CLI** के माध्यम से कमांड लाइन पर उपलब्ध है।

## FFmpeg कमांड लाइन, FFmpeg सिंटैक्स के बिना

FFmpeg की नेटिव कमांड लाइन शक्तिशाली है लेकिन बेहद कठोर मानी जाती है। **EncodeX CLI** इसे सरल, पठनीय कमांड में लपेटती है:

```bash
encodex convert input.mp4 output.avi --video-codec libx265 --audio-codec aac
encodex info input.mp4 --json
encodex compress photo.png -f jpg -q 30
encodex extract-audio input.mp4
encodex batch 'videos/**/*.mov' --concurrency 2 --output-dir converted
```

कोई गूढ़ `-c:v libx264 -crf 23 -preset medium` श्रृंखला नहीं — बस स्पष्ट विकल्प फ़्लैग्स, GUI के समान सेटिंग्स, और साफ़ आउटपुट।

## EncodeX CLI क्यों उपयोग करें?

- **स्क्रिप्ट करें** — cron jobs, CI pipelines और सर्वरों में कन्वर्ज़न को स्वचालित करें
- **सुसंगत** — GUI के समान इंजन और प्रोफ़ाइल
- **बैच-फ़्रेंडली** — समानांतर कार्य के लिए glob पैटर्न और `--concurrency`
- **पठनीय** — आप बिना मैनुअल के टाइप कर सकते हैं
- **क्रॉस-प्लेटफ़ॉर्म** — Windows, macOS और Linux पर काम करता है
- **हेडलेस** — डेस्कटॉप की आवश्यकता नहीं, सर्वर के लिए बिल्कुल सही

## CLI कमांड

| कमांड              | क्या करता है                                              |
| ------------------ | --------------------------------------------------------- |
| `encodex convert`  | एक फ़ाइल को दो प्रारूपों के बीच कन्वर्ट करता है           |
| `encodex batch`    | glob पैटर्न के साथ कई फ़ाइलें समानांतर में कन्वर्ट करता है  |
| `encodex compress`  | वीडियो या छवि फ़ाइल को कंप्रेस करता है                    |
| `encodex extract-audio` | वीडियो से ऑडियो ट्रैक निकालता है                   |
| `encodex info`     | फ़ाइल को प्रोब करता है और इसकी तकनीकी जानकारी प्रिंट करता है |
| `encodex capabilities` | समर्थित प्रारूप और एन्कोडर सूचीबद्ध करता है          |

## CLI प्राप्त करें

CLI **हर EncodeX इंस्टॉल** के साथ आती है — ऐप डाउनलोड करें और आप अपने टर्मिनल से `encodex` कॉल कर सकते हैं। अलग सेटअप की आवश्यकता नहीं।

## अक्सर पूछे जाने वाले प्रश्न

**CLI का उपयोग करने के लिए क्या मुझे GUI चाहिए?** नहीं, CLI स्वतंत्र रूप से काम करती है। यह हर EncodeX इंस्टॉल के साथ बंडल आती है।

**क्या मैं EncodeX CLI का उपयोग सर्वर पर कर सकता हूँ?** हाँ — यह हेडलेस है, इसलिए स्क्रिप्ट, CI और सर्वर वातावरण में बहुत अच्छा काम करती है।

**क्या EncodeX CLI वास्तव में मुफ़्त है?** हाँ — EncodeX हमेशा के लिए मुफ़्त है और ओपन सोर्स (MIT) है।
