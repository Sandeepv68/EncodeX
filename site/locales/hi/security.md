# EncodeX पर सुरक्षा

EncodeX ओपन सोर्स है, इसलिए सुरक्षा को भरोसे पर नहीं लेना पड़ता। हर रिलीज़ सार्वजनिक कोड से बनती है और प्रकाशित **SHA-256 चेकसम** के साथ आती है, जिसकी तुलना आप अपने डाउनलोड से कर सकते हैं। रिलीज़ बिल्ड **कोड-साइन नहीं** हैं, इसलिए आपका OS "अनजान डेवलपर" की चेतावनी दिखा सकता है।

## जो हम भेजते हैं, उसे आप जाँच सकते हैं

- **ओपन सोर्स।** पूरा ऐप — मीडिया-प्रोसेसिंग पाइपलाइन और रिलीज़ स्क्रिप्ट सहित — [हमारे रेपो](https://github.com/Sandeepv68/EncodeX) में रहता है। कोई भी जाँच सकता है कि ऐप असल में क्या करता है।
- **SHA-256 चेकसम।** हर रिलीज़ अपनी बाइनरी के साथ `SHA256SUMS.txt` फ़ाइल प्रकाशित करती है। इंस्टॉल करने से पहले डाउनलोड की गई फ़ाइल की तुलना प्रकाशित हैश से करें:

```bash
# Windows (PowerShell)
Get-FileHash .\EncodeX-Setup-1.0.0.exe -Algorithm SHA256

# macOS / Linux
shasum -a 256 ./EncodeX-1.0.0.dmg
```

- **वेरिफ़ाइड अपडेट।** अपडेटर GitHub Releases देखता है। जब GitHub अपडेट फ़ाइल के लिए SHA-256 या SHA-512 digest प्रकाशित करता है, तो ऐप डाउनलोड को उससे मिलाता है। अपडेटर क्रिप्टोग्राफ़िक सिग्नेचर वेरिफ़ाई नहीं करता। अपडेट अपने आप इंस्टॉल नहीं होते; आप तय करते हैं कि कब इंस्टॉल करना है।

## macOS Gatekeeper नोट

क्योंकि EncodeX मुफ़्त और ओपन सोर्स है, Mac App Store पर नहीं बिकता, और इसके macOS बिल्ड कोड-साइन या notarize नहीं हैं, macOS पहली बार "खोला नहीं जा सकता" जैसा संदेश दिखा सकता है। यह रिलीज़ पेज पर प्रकाशित वही बिल्ड है। इसे खोलने के लिए Applications में ऐप पर Control-क्लिक करें और एक बार **Open** चुनें। नए macOS संस्करणों पर **सिस्टम सेटिंग्स → Privacy & Security → Open Anyway** इस्तेमाल करना पड़ सकता है। उसके बाद यह सामान्य रूप से खुलता है।

## बंडल किया हुआ FFmpeg

EncodeX सिस्टम बाइनरी बुलाने के बजाय `ffmpeg-static` और `ffprobe-static` पैकेज के प्रीबिल्ट FFmpeg और FFprobe बाइनरी बंडल करता है। रूपांतरण आपके डिवाइस पर एक चाइल्ड प्रोसेस के रूप में चलते हैं। इंजन कैसे जुड़ा है, यह हमारे [तकनीकी आर्किटेक्चर](/hi/docs/architecture) में देखें।

## वल्नरेबिलिटी रिपोर्ट करना

हम सुरक्षा गंभीरता से लेते हैं और एक सीधा डिस्क्लोज़र प्रक्रिया चलाते हैं:

1. वल्नरेबिलिटी को **सार्वजनिक GitHub issues में न रिपोर्ट करें** — इससे हमारे ठीक करने से पहले ही खामी सामने आ जाएगी।
2. रेपो पर **[प्राइवेट सिक्योरिटी एडवाइज़री](https://github.com/Sandeepv68/EncodeX/security/advisories/new)** खोलें।
3. हम **48 घंटों के भीतर** रसीद स्वीकार करते हैं और फ़िक्स की अनुमानित समयसीमा देते हैं। सुरक्षा फ़िक्स को प्राथमिकता मिलती है और वे जल्द से जल्द रिलीज़ होते हैं।

बाकी सब के लिए, [नियमित issue ट्रैकर](https://github.com/Sandeepv68/EncodeX/issues) इस्तेमाल करें।
