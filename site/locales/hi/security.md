# EncodeX पर सुरक्षा

EncodeX ओपन सोर्स है, इसलिए सुरक्षा को भरोसे पर नहीं लेना पड़ता — हर रिलीज़ सार्वजनिक कोड से बनती है, **SHA-256 चेकसम** के साथ आती है जिसे आप जाँच सकते हैं, और जहाँ संभव हो **कोड-साइन किया** जाता है ताकि आपका ऑपरेटिंग सिस्टम पक्का कर सके कि यह सच में हमसे आई है।

## जो हम भेजते हैं, उसे आप जाँच सकते हैं

- **ओपन सोर्स।** पूरा ऐप — मीडिया-प्रोसेसिंग पाइपलाइन और बंडल किया गया FFmpeg बिल्ड सहित — [हमारे रेपो](https://github.com/Sandeepv68/EncodeX) में रहता है। कोई भी जाँच सकता है कि ऐप असल में क्या करता है।
- **SHA-256 चेकसम।** हर रिलीज़ बाइनरी के साथ चेकसम प्रकाशित करती है। इंस्टॉल करने से पहले डाउनलोड की गई फ़ाइल की तुलना प्रकाशित हैश से करें:

```bash
# Windows (PowerShell)
Get-FileHash .\EncodeX-Setup-1.0.0.exe -Algorithm SHA256

# macOS / Linux
shasum -a 256 ./EncodeX-1.0.0.dmg
```

- **कोड-साइनिंग।** Windows और macOS रिलीज़ साइन की जाती हैं, इसलिए आपका OS "वेरिफ़ाइड पब्लिशर"/"Apple" दिखाता है, "अनजान डेवलपर" की चेतावनी नहीं।
- **वेरिफ़ायबल अपडेट।** ऐप HTTPS पर सिर्फ़ हमारे द्वारा साइन किए गए अपडेट डाउनलोड करता है। कुछ भी बदलने से पहले अपडेट का सिग्नेचर स्थानीय रूप से वैलिडेट होता है।

## macOS Gatekeeper नोट

क्योंकि EncodeX मुफ़्त और ओपन सोर्स है (और Mac App Store पर नहीं बिकता), macOS पहली बार "खोला नहीं जा सकता" जैसा संदेश दिखा सकता है — यह डिफ़ॉल्ट रूप से अनसाइन ऐप्स के लिए **Gatekeeper** की जाँच होती है। बिल्ड असली है; इसे खोलने के लिए Applications में ऐप पर Control-क्लिक करें और एक बार **Open** चुनें। उसके बाद यह सामान्य रूप से खुलता है।

## बंडल किया हुआ FFmpeg

EncodeX सिस्टम बाइनरी बुलाने के बजाय अपना खुद का FFmpeg बिल्ड बंडल करता है। सटीक बिल्ड (वर्ज़न, स्रोत और कॉन्फ़िगरेशन) हमारे [तकनीकी आर्किटेक्चर](/hi/docs/architecture) में दस्तावेज़ित है और CI में स्रोत से दोबारा बनता है — इसलिए कन्वर्ज़न हर जगह एक जैसे होते हैं, और आप वही बाइनरी चलाते हैं जो हमने बनाई है।

## वल्नरेबिलिटी रिपोर्ट करना

हम सुरक्षा गंभीरता से लेते हैं और एक सीधा डिस्क्लोज़र प्रक्रिया चलाते हैं:

1. वल्नरेबिलिटी को **सार्वजनिक GitHub issues में न रिपोर्ट करें** — इससे हमारे ठीक करने से पहले ही खामी सामने आ जाएगी।
2. रेपो पर **[प्राइवेट सिक्योरिटी एडवाइज़री](https://github.com/Sandeepv68/EncodeX/security/advisories/new)** खोलें।
3. हम **48 घंटों के भीतर** रसीद स्वीकार करते हैं और फ़िक्स की अनुमानित समयसीमा देते हैं। सुरक्षा फ़िक्स को प्राथमिकता मिलती है और वे जल्द से जल्द रिलीज़ होते हैं।

बाकी सब के लिए, [नियमित issue ट्रैकर](https://github.com/Sandeepv68/EncodeX/issues) इस्तेमाल करें।
