# Casos de uso — ¿Qué puede hacer EncodeX?

## ¿Para quién es EncodeX?

**Creadores de contenido** — comprime para subir, extrae audio, convierte formatos.
**Estudiantes** — convierte grabaciones de clase en notas de audio, recorta grabaciones largas.
**Podcasters** — extrae pistas de audio y comprime para la distribución.
**Desarrolladores** — conversión por lotes, scripts con la CLI, análisis de archivos con la API.
**Todos los demás** — si "formato de archivo" te suena a jerga, EncodeX fue hecho para ti.
