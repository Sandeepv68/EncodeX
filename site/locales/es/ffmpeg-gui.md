# Una potente GUI para FFmpeg

**FFmpeg** es el motor que está detrás de casi todas las herramientas de conversión de vídeo, pero es un programa de línea de comandos difícil de usar. **EncodeX** te ofrece un **frontend de FFmpeg** amigable y visual que envuelve todo ese poder en una interfaz que cualquiera puede usar, sin escribir un solo comando.

## ¿Por qué poner una GUI alrededor de FFmpeg?

FFmpeg es increíblemente potente. El problema es que usarlo significa memorizar comandos como:

```bash
ffmpeg -i input.mkv -c:v libx264 -crf 18 -c:a aac output.mp4
```

Si eso te parece un idioma extranjero, no estás solo. Una **GUI de FFmpeg** convierte eso en simples menús y botones:

- **Elige tu archivo** arrastrándolo a la ventana
- **Elige tu salida** — un dispositivo, una plataforma o un formato como MP4
- **Haz clic en Convertir** y deja que EncodeX haga el resto

## Qué puedes hacer con la GUI de FFmpeg de EncodeX

- **Convertir vídeo y audio** entre docenas de formatos — MP4, MKV, AVI, MOV, WebM, MP3, FLAC, WAV y más
- **Comprimir vídeos** para reducir el tamaño sin arruinar la calidad
- **Recortar clips** visualmente — arrastra dos controles en una línea de tiempo, listo
- **Extraer audio** de un vídeo y guardarlo como MP3
- **Procesar por lotes** carpetas enteras de archivos de una sola vez
- **Aceleración por hardware** con NVENC, QSV, AMF, VAAPI y VideoToolbox para codificar mucho más rápido
