# Codificador VP9 y convertidor de vídeo

**VP9** es el códec de vídeo abierto y libre de regalías de Google — el motor detrás de YouTube, Chrome y Android. **EncodeX** es un **convertidor de vídeo VP9** gratuito que te permite codificar a VP9 cuando quieres vídeo eficiente, abierto y listo para la web.

## ¿Por qué VP9?

VP9 ofrece mucho rendimiento para un códec de uso gratuito:

- **Excelente compresión** — aproximadamente la mitad del tamaño de H.264 con calidad similar
- **Libre de regalías** y estándar abierto
- **Listo para la web** — compatible con navegadores modernos, YouTube y Android
- **Excelente para streaming** — eficiente en contenido de alta resolución y alta frecuencia de actualización

## Cuándo usar VP9 vs AV1 vs H.264

- Elige **H.264** para máxima compatibilidad con dispositivos antiguos
- Elige **VP9** para un códec abierto, eficiente y listo para la web
- Elige **AV1** para los archivos más pequeños posibles (el sucesor de VP9)
- Elige **H.265/HEVC** para un gran equilibrio entre tamaño y compatibilidad

EncodeX facilita la comparación — convierte un clip de prueba a cada códec y observa la diferencia en tamaño y calidad.
