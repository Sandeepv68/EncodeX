# Pruebas

## Comandos

```bash
# Run all tests
npm test

# Watch mode
npm run test:watch

# With coverage report
npm run test:coverage

# Unit tests only
npm run test:unit

# Integration tests (matches src/**/*.integration.{test,spec}.{ts,tsx})
npm run test:integration

# E2E tests (requires build)
npm run test:e2e
```

Los reportes de cobertura se generan en `coverage/`:

- `coverage/index.html` — HTML navegable
- `coverage/lcov.info` — LCOV para integración con IDEs

## Configuración de pruebas

El entorno de pruebas (`src/test-setup.ts`) proporciona:

- Mock de `useTranslation` de `react-i18next` con mapeo de claves al inglés e interpolación
- Mock de `electronAPI` en `globalThis` cubriendo todos los métodos IPC
- Registro de matchers `@testing-library/jest-dom/vitest`

## Pruebas E2E

Las pruebas end-to-end basadas en Playwright viven en `e2e/` (entorno node, timeouts de 60 s) y están condicionadas a la variable de entorno `E2E` o a CI:

| Archivo              | Qué cubre                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------- |
| `e2e/cli.spec.ts` | Modo CLI: `--help`/`-h`, subcomandos (`convert`, `info`, `capabilities`, `compress`, `extract-audio`, `batch`), sintaxis plana heredada, flags globales (`--quiet`, `--no-color`, `--theme`) |
| `e2e/specs/shell.spec.ts` | Shell de la app: título de la ventana, presencia de `electronAPI`, todas las rutas de navegación, navegación del drawer, controles de ventana, menú de idiomas |
| `e2e/specs/convert.spec.ts` | Página Convert: selección de archivos, autocompletado de salida, opciones de códec/bitrate/escala/píxel/transcoder, copia sin pérdida, conversión con progreso, pausa/reanudación, cancelar |
| `e2e/specs/batch.spec.ts` | Cola por lotes: estado vacío, añadir archivos vía diálogo de revisión, eventos de cola, progreso en vivo, cancelar todo, filtro de estado, eliminar trabajo, reordenar arrastrando, confirmación de cierre de ventana |
| `e2e/specs/audio-extract.spec.ts` | Extracción de audio: botón deshabilitado, selección de vídeo con streams de audio, cambios de códec/bitrate, extracción con toast de éxito |
| `e2e/specs/image-compress.spec.ts` | Compresión de imágenes: dropzone, selección de imagen con vista previa, cambios de formato/calidad/escala, compresión con toast de éxito |
| `e2e/specs/media-info.spec.ts` | Media info: análisis de vídeo (streams, detalles de códecs), análisis de imagen (datos EXIF) |
| `e2e/specs/settings.spec.ts` | Ajustes: tarjetas de tema, cambio de tema, siempre visible, lanzar al inicio, persistencia del modo hwaccel |
| `e2e/specs/logs.spec.ts` | Logs: emisión de entradas, filtrado por nivel, limpiar todo, descarga con toast |
| `e2e/specs/video-cut.spec.ts` | Corte de vídeo: botón deshabilitado, línea de tiempo + forma de onda + miniaturas, alternancia duración/hora-fin, arrastre del cabezal, corte con progreso, cancelar, limpiar formulario |
| `e2e/specs/real-convert.spec.ts` | Tier B (real): conversión FFmpeg real sin mocks (condicionada a `E2E_REAL=1`) |
