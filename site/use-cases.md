# Use Cases — What Can EncodeX Do?

EncodeX is a free, open-source FFmpeg GUI built for real-world media tasks — whether you're compressing a video for upload, extracting audio from a podcast, or converting a batch of files overnight.

## Who is EncodeX for?

**Content creators** — compress for upload, extract audio, convert formats.
**Students** — turn recorded lectures into audio notes, trim long recordings.
**Podcasters** — extract audio tracks, compress for distribution.
**Developers** — batch-convert, script with the CLI, probe media with the API.
**Everyone else** — if "file format" sounds like jargon, EncodeX was made for you.
